🔑 Build Each Coefficient Fresh

You can already do T₃+T₅. The trap is treating it as a memorised chunk — then T₂+T₆ or T₄+T₇ throws you. Today there is no memorising: you build the coefficient of d for any term from one rule, so every pair works the same way.

🔍 One rule: Tk = a + (k − 1) × d

The number of d's in a term is always (position − 1). T₂ has 1 d, T₅ has 4 d, T₇ has 6 d. Never guess — subtract 1 from the position, every time.

The 3-Step Method (works for every pair)

  1. Write each term as a + (position−1)d.
  2. Add them: 2a + (the two d-counts added) × d = the given sum.
  3. Solve for a.

Example: T₂ + T₆ = 70, with d = 4. Find a.

T₂ = a + 1d
T₆ = a + 5d
d-counts: (2−1)=1 and (6−1)=5← build fresh, don't recall
add: 2a + (1+5)d = 2a + 6d
2a + 6×4 = 70 → 2a + 24 = 70
2a = 46 → a = 23← check: T₂=27, T₆=43, 27+43=70 ✓

Same Method, Different Pairs

The ONLY thing that changes is the two d-counts. Watch how the trained T₃+T₅ and a "scary" T₄+T₇ are the exact same job.

T₃ + T₅ = 50, d = 6

d-counts (3−1)=2, (5−1)=4 → 2a + 6d
2a + 36 = 50 → 2a = 14 → a = 7

T₄ + T₇ = 89, d = 7 (a "novel" pair — same job)

d-counts (4−1)=3, (7−1)=6 → 2a + 9d
2a + 63 = 89 → 2a = 26 → a = 13

❌ The old slip: reusing "2a + 6d" (from T₃+T₅) on a different pair. The d-count is NOT fixed — it is (pos−1)+(pos−1) for the actual two positions. Re-derive it every single time.

Then Go One Step Further

Harder questions ask for another term after you find a. Find a first, then use Tk = a + (k−1)d again.

Example: T₂ + T₆ = 70 (d = 4) gave a = 23. Find T₁₀.

T₁₀ = a + (10−1)d = 23 + 9×4
= 23 + 36 = 59

Practice

For each term: d-count = position − 1. Add the two counts, build 2a + (count)d = sum, solve for a.

Q1.   T₂ + T₄ = 40 and d = 6. Find the first term a.
counts (2−1)=1,(4−1)=3 → 2a+4d. 2a+24=40 → a=8
Q2.   T₃ + T₆ = 63 and d = 3. Find the first term a.
counts (3−1)=2,(6−1)=5 → 2a+7d. 2a+21=63 → a=21
Q3.   T₄ + T₇ = 89 and d = 7. Find the first term a.
counts (4−1)=3,(7−1)=6 → 2a+9d. 2a+63=89 → a=13
Q4.   T₂ + T₅ = 44 and d = 4. Find the first term a.
counts (2−1)=1,(5−1)=4 → 2a+5d. 2a+20=44 → a=12
📖 Two-Term Sums — The Whole Method
d-count:each term has (position − 1) d's. Always subtract 1. Add the pair:2a + (count₁ + count₂) × d = sum. Solve:take the d-part off, then ÷ 2 for a. Never reuse:re-derive the counts for the actual positions each time. Then a term:Tₖ = a + (k−1)d.
