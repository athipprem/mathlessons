🔑 First, the One Rule

Every term in an arithmetic sequence is built from the same rule. We use the letter p for the position — that is, which term we want.

Tp = a + (p − 1) × d
What each letter means:
• p = the position (which term). For T₂, p = 2. For T₆, p = 6. For T₇, p = 7.
• a = the first term (T₁).
• d = the common difference (the jump between terms).

The important part: how many d's?

The number of d's in a term is always (p − 1) — the position minus 1.

T₂ → (2−1) = 1 d
T₆ → (6−1) = 5 d's
T₇ → (7−1) = 6 d's

Never guess this number. Always do position − 1.

The 3-Step Method (works for every pair)

Remember the rule:  Tp = a + (p − 1) × d
  1. Write each term using the rule (work out its d-count = position − 1).
  2. Add the two terms together and tidy up to get 2a + (some number)d = the given sum.
  3. Put in the value of d, then solve for a step by step.

Worked Example: T₂ + T₆ = 70, and d = 4. Find a.

Step 1 — write each term with the rule
Tp = a + (p − 1) × d ← the rule
T₂ = a + (2 − 1)d ← put p = 2
T₂ = a + 1d
T₆ = a + (6 − 1)d ← put p = 6
T₆ = a + 5d
Step 2 — the question says T₂ + T₆ = 70, so add them
(a + 1d) + (a + 5d) = 70
(a + a) + (1d + 5d) = 70 ← group the a's and the d's
2a + 6d = 70
Step 3 — put in d = 4 and solve
2a + (6 × 4) = 70 ← we know d = 4
2a + 24 = 70
2a = 70 − 24 ← take 24 off both sides
2a = 46
a = 46 ÷ 2 ← halve both sides
a = 23
Check
T₂ = 23 + 1×4 = 27,  T₆ = 23 + 5×4 = 43
27 + 43 = 70 ✓ ← matches the question

Same Method, Different Pairs

Remember the rule:  Tp = a + (p − 1) × d

The ONLY thing that changes from pair to pair is the two d-counts. Everything else is the same job.

Example A: T₃ + T₅ = 50, and d = 6. Find a.

T₃ = a + (3 − 1)d = a + 2d ← p = 3
T₅ = a + (5 − 1)d = a + 4d ← p = 5
(a + 2d) + (a + 4d) = 50
(a + a) + (2d + 4d) = 50
2a + 6d = 50
2a + (6 × 6) = 50 ← d = 6
2a + 36 = 50
2a = 50 − 36
2a = 14
a = 14 ÷ 2
a = 7
Check: T₃ = 7 + 2×6 = 19, T₅ = 7 + 4×6 = 31, 19 + 31 = 50 ✓

Example B: T₄ + T₇ = 89, and d = 7. Find a. (a "tricky" pair — same steps)

T₄ = a + (4 − 1)d = a + 3d ← p = 4
T₇ = a + (7 − 1)d = a + 6d ← p = 7
(a + 3d) + (a + 6d) = 89
(a + a) + (3d + 6d) = 89
2a + 9d = 89
2a + (9 × 7) = 89 ← d = 7
2a + 63 = 89
2a = 89 − 63
2a = 26
a = 26 ÷ 2
a = 13

❌ The old mistake: copying "2a + 6d" from Example A onto Example B. The d-count is NOT always 6 — here it is 3 + 6 = 9. Always re-do (position − 1) for the two real positions.

One Step Further: Find Another Term

Remember the rule:  Tp = a + (p − 1) × d

Some questions ask for another term after you find a. Find a first, then use the same rule again with the new position.

Example: T₂ + T₆ = 70 (d = 4). We found a = 23. Now find T₁₀.

Tp = a + (p − 1) × d ← the same rule
T₁₀ = a + (10 − 1)d ← put p = 10
T₁₀ = 23 + 9d ← put a = 23
T₁₀ = 23 + (9 × 4) ← put d = 4
T₁₀ = 23 + 36
T₁₀ = 59

Practice

For each term: d-count = position − 1. Add the two terms, tidy to 2a + (number)d = sum, put in d, then solve for a.

Q1.   T₂ + T₄ = 40 and d = 6. Find the first term a.
T₂ = a + (2−1)d = a + 1d
T₄ = a + (4−1)d = a + 3d
(a + 1d) + (a + 3d) = 40
2a + 4d = 40
2a + (4×6) = 40 → 2a + 24 = 40
2a = 16 → a = 8
Q2.   T₃ + T₆ = 63 and d = 3. Find the first term a.
T₃ = a + (3−1)d = a + 2d
T₆ = a + (6−1)d = a + 5d
(a + 2d) + (a + 5d) = 63
2a + 7d = 63
2a + (7×3) = 63 → 2a + 21 = 63
2a = 42 → a = 21
Q3.   T₂ + T₅ = 44 and d = 4. Find the first term a.
T₂ = a + (2−1)d = a + 1d
T₅ = a + (5−1)d = a + 4d
(a + 1d) + (a + 4d) = 44
2a + 5d = 44
2a + (5×4) = 44 → 2a + 20 = 44
2a = 24 → a = 12
Q4.   T₃ + T₇ = 88 and d = 5. Find the first term a.
T₃ = a + (3−1)d = a + 2d
T₇ = a + (7−1)d = a + 6d
(a + 2d) + (a + 6d) = 88
2a + 8d = 88
2a + (8×5) = 88 → 2a + 40 = 88
2a = 48 → a = 24
📖 The Whole Method, In Order
The rule:Tp = a + (p − 1) × d  (p = position). d-count:each term has (position − 1) d's. Re-do it for every term. Add the pair:2a + (count₁ + count₂) × d = sum. Put in d, solve:subtract the d-part, then ÷ 2 to get a. Then a term:use Tp = a + (p−1)d again with the new position. Always check:work out the two terms and add — do they make the sum?

🏆 You are ready when...

  • Any pair — T₂+T₇, T₃+T₈ — feels the same as T₃+T₅
  • You write (position − 1) for each term before adding
  • You never paste an old "2a + 6d" onto a new pair
