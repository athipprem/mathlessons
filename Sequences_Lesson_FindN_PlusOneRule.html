Why Do We Always Add +1?

You already know the Gap Method for finding n. But sometimes you forget the +1 at the end — and the answer is off by 1. Today we are going to lock this rule forever by understanding exactly why it is there.

💡 Count the DOTS or the GAPS?

Look at this sequence and count carefully:

T₁
→Jump 1
T₂
→Jump 2
T₃
→Jump 3
T₄
→Jump 4
T₅
Count Number Why
Dots (terms) 5 T₁, T₂, T₃, T₄, T₅
Jumps (gaps) 4 Jump 1, Jump 2, Jump 3, Jump 4

Golden Rule: Dots = Jumps + 1.  Always.  T₁ exists before any jump happens.

✅ So for Find n:

Gap Method gives us: Jumps = (Tₙ − a) ÷ d
But we want DOTS (term number), not GAPS (jumps)
So: n = Jumps + 1← because Dots = Jumps + 1, always

Two Types — Same +1 Rule

The +1 rule appears in two different question types. You must handle each one correctly.

🔍 Type A — Which term equals X?

You are given a, d, and a target value Tₙ. You need to find which term number it is.

Rule: n = Jumps + 1 (add 1 at the end)

🟠 Type B — Last term above zero?

The sequence is decreasing. You need the last term that is still positive (above zero).

Rule: Stop at the last POSITIVE term — check T and T+1

Type A — Worked Example

a = 7, d = 4, Tₙ = 67. Find n.

Write: Tₙ = a + (n−1)×d← always write the formula first
Step 1: Distance = 67 − 7 = 60← how far from a to Tₙ
Step 2: Jumps = 60 ÷ 4 = 15← distance ÷ d
Step 3: n = 15 + 1 = 16← Jumps + 1 (dots > gaps by 1)
✓ Check: T₁₆ = 7 + 15×4 = 7 + 60 = 67 ✓← always verify

Type B — Worked Example

a = 70, d = −8. Which is the last term above zero?

Write: Tₙ = 70 + (n−1)×(−8)← formula with negative d
Set Tₙ > 0:← we want ABOVE zero, not at zero
70 − 8(n−1) > 0
8(n−1) < 70
n−1 < 8.75
n < 9.75← n must be a whole number, so n can be at most 9
✓ Check T₉ = 70 + 8×(−8) = 70 − 64 = 6 > 0 ✓
✗ Check T₁₀ = 70 + 9×(−8) = 70 − 72 = −2 < 0 ✗← confirms T₉ is the last positive term
Answer: T₉

⚠ Always check both Tₙ (should be positive) and Tₙ₊₁ (should be negative or zero). This proves you found the correct last term.

The Two Most Common Mistakes

Knowing the mistake makes it much easier to avoid.

❌ Mistake 1 — Forgetting +1 in Type A

a = 5, d = 4, Tₙ = 65. Find n.

❌ Wrong method

Distance = 65−5 = 60
Jumps = 60÷4 = 15
n = 15 ← STOP! Forgot +1!

✅ Correct method

Distance = 65−5 = 60
Jumps = 60÷4 = 15
n = 15 + 1 = 16 ✓

📌 The check reveals the error: T₁₅ = 5 + 14×4 = 61 ≠ 65. That's why we always check!

❌ Mistake 2 — Going one step too far in Type B

a = 84, d = −7. Last term above zero.

❌ Wrong: goes too far

84−7(n−1) > 0
n < 13
Answer: T₁₂ ← wrong!
T₁₂ = 84−77 = 7 ✓
T₁₃ = 84−84 = 0 (not > 0!)

✅ Correct: check both

n < 13 → n can be 12
T₁₂ = 7 > 0 ✓
T₁₃ = 0 (NOT > 0) ✓
Answer: T₁₂ ✓

⚠ If the question says “above zero”, zero itself does NOT count. Always check both Tₙ and Tₙ₊₁.

Practice

Write the formula Tₙ = a + (n−1)×d first, then apply the steps. Always verify your answer.

Q1.   A sequence has a = 7 and d = 4. One of its terms equals 67. Which term number is that?
Write: Tₙ = a + (n−1)×d
Step 1: Distance = 67 − 7 = 60
Step 2: Jumps = 60 ÷ 4 = 15
Step 3: n = 15 + 1 = 16
Check: T₁₆ = 7 + 15×4 = 67 ✓
Q2.   A sequence has a = 6 and d = 8. One of its terms equals 102. Which term number is that?
Write: Tₙ = 6 + (n−1)×8
Step 1: Distance = 102 − 6 = 96
Step 2: Jumps = 96 ÷ 8 = 12
Step 3: n = 12 + 1 = 13
Check: T₁₃ = 6 + 12×8 = 102 ✓
Q3.   A sequence has a = 5 and d = 8. Which is the first term to exceed 100? (Hint: the answer is NOT T₁₂.)
Write: 5 + (n−1)×8 > 100
8(n−1) > 95
n−1 > 11.875 → n > 12.875 → n = 13
Check T₁₃ = 5 + 12×8 = 101 > 100 ✓
Check T₁₂ = 5 + 11×8 = 93 < 100 ✓ (confirms T₁₃ is first)
Q4.   A decreasing sequence has a = 70 and d = −8. What is the last term that is still above zero?
Write: 70 + (n−1)×(−8) > 0
70 − 8(n−1) > 0 → 8(n−1) < 70 → n−1 < 8.75
n < 9.75 → largest whole number is n = 9
Check T₉ = 70 + 8×(−8) = 70−64 = 6 > 0 ✓
Check T₁₀ = 70 + 9×(−8) = 70−72 = −2 < 0 ✓ (confirms T₉ is last positive)
📖 What You Learned Today
Dots vs Gaps: There are always MORE dots than gaps. Dots = Jumps + 1. Find n (Type A): Distance → Jumps → n = Jumps + 1. Always add 1 at the end. Last above zero (Type B): Solve Tₙ > 0 to get n < something. Take the largest whole number. Check both T and T+1. First exceeding X: Solve Tₙ > X. Take the smallest whole number n that satisfies it. Check both T and T−1. Always verify: Plug n back into the formula. 5 seconds that catches all errors.

🏆 You are ready for the test when...

  • You always write Tₙ = a + (n−1)×d before starting
  • You never stop at Jumps — you always do n = Jumps + 1
  • You always check both Tₙ and the one next to it
