Every Term Has an “Address”

Each term in a sequence is a fixed number of jumps away from T₁. The jump diagram shows this clearly:

(= a)

T₅
4 jumps

T₃ is 2 jumps from T₁, so T₃ = a + 2d. T₅ is 4 jumps from T₁, so T₅ = a + 4d.

💡 The key pattern

Tₙ is always (n−1) jumps from T₁. That is where the formula Tₙ = a + (n−1)×d comes from — it is literally just counting the jumps!

T₃ = a + (3−1) × d = a + 2d← 3rd term, so 2 jumps
T₆ = a + (6−1) × d = a + 5d← 6th term, so 5 jumps
T₁₀ = a + (10−1) × d = a + 9d← 10th term, so 9 jumps

Writing the Expression for Any Term

Before you can solve a two-term problem, you must be able to write the expression for each term. Use the table below as your guide:

TermJumps from T₁Expression
T₁0 jumpsa
T₂1 jumpa + 1d = a + d
T₃2 jumpsa + 2d
T₄3 jumpsa + 3d
T₅4 jumpsa + 4d

📌 The exponent of d is always one less than the term number. T₃ has 2d, not 3d.

Two-term puzzle: what if T₃ + T₅ = 64 and d = 4?

Step 1: Write the expression for each term using the table above.

T₃ = a + 2d = a + 2(4) = a + 8← 3rd term = 2 jumps from start
T₅ = a + 4d = a + 4(4) = a + 16← 5th term = 4 jumps from start

Step 2: Add them together and solve.

(a + 8) + (a + 16) = 64← the two expressions must add to 64
2a + 24 = 64← collect: a+a=2a, and 8+16=24
2a = 40← subtract 24 from both sides
a = 20← divide both sides by 2

Worked Examples — Express and Add

Example 1  d = 5, T₁ + T₃ = 36. Find a.

T₁ = a← first term = 0 jumps = just a
T₃ = a + 2d = a + 2(5) = a + 10← 3rd term = 2 jumps of size 5
T₁ + T₃ = a + (a + 10) = 36← add the two expressions, set equal to 36
2a + 10 = 36← collect: a+a=2a
2a = 26← subtract 10
a = 13← divide by 2
✓ Check: T₁=13, T₃=13+10=23. Sum=36 ✓← always verify!

Example 2  d = 3, T₂ + T₅ = 39. Find a.

T₂ = a + 1d = a + 3← 2nd term = 1 jump of size 3
T₅ = a + 4d = a + 12← 5th term = 4 jumps of size 3
(a + 3) + (a + 12) = 39← add expressions
2a + 15 = 39← collect: 3+12=15
2a = 24← subtract 15
a = 12← divide by 2
✓ Check: T₂=15, T₅=24. Sum=39 ✓← always verify!

📋 The Express-and-Add Method (4 steps)

1
Write the expression for each term (use jumps table)
2
Add the two expressions together
3
Collect like terms (2a + number)
4
Solve for a, then check your answer

Practice — Find a (First Term)

Write expressions for both terms, add them, collect, solve. Always check!

Q1. In an arithmetic sequence, d = 4. The second and fourth terms add up to 48.
That is, T₂ + T₄ = 48. Find the first term a.
T₂ = a + d = a + 4
T₄ = a + 3d = a + 12
(a+4) + (a+12) = 48
2a + 16 = 48
2a = 32 → a = 16
Check: T₂=20, T₄=28. Sum=48 ✓
Q2. In an arithmetic sequence, d = 3. The third and sixth terms add up to 45.
That is, T₃ + T₆ = 45. Find the first term a.
T₃ = a + 2d = a + 6
T₆ = a + 5d = a + 15
(a+6) + (a+15) = 45
2a + 21 = 45
2a = 24 → a = 12
Check: T₃=18, T₆=27. Sum=45 ✓
Q3. In an arithmetic sequence, d = 7. The second and fourth terms add up to 56.
That is, T₂ + T₄ = 56. Find the first term a.
T₂ = a + d = a + 7
T₄ = a + 3d = a + 21
(a+7) + (a+21) = 56
2a + 28 = 56
2a = 28 → a = 14
Check: T₂=21, T₄=35. Sum=56 ✓

Lesson Summary

🎯You can now find a when two terms add up to a given total!
📌Tₙ = a + (n−1)d  —  the number of d’s is one less than n
1️⃣Write the expression for each term (use the jumps table)
2️⃣Add the two expressions → collect like terms → solve for a
✓Always check: substitute a back in and verify the sum

Quick example: d = 6, T₂ + T₄ = 54 → find a

T₂ = a+6,  T₄ = a+18
(a+6) + (a+18) = 54
2a + 24 = 54 → 2a = 30 → a = 15
Check: 21+33 = 54 ✓
