🗺️ Prem's Sequences Pocket Map

Every sequences question is just ONE of four moves. Find your move, follow the steps.

🔑 The One Rule Behind Everything

Jumps = n − 1

5 fence posts, only 4 rails. T₅ is 4 jumps from the start — never 5.
Forgot the +1? Wrote a+4d for T₄? That's this rule. It's ALL this rule.

Question 1: Do I know a (the first term)?
NO ⬇YES ⬇

🔎 First: FIND a — then come back to Question 2

Given one middle term? Walk back its jumps:

a = Tₘ − (m−1)×d   (T₆ given? go back 5 jumps, not 6!)

Given two terms? Gap Method: d = (difference of values) ÷ (jumps between them), then walk back.

Given a two-term SUM? Use the Expand & Add move below.

Question 2: What does the question WANT?
⬇⬇

➡️ FORWARD — I know n, I want the value

"What is T₁₅?" → take n−1 jumps forward.

Tₙ = a + (n−1)×d

a=4, d=6, T₁₅? → 4 + 14×6 = 88

⬅️ BACKWARD — I know the value, I want n

"Which term equals 88?" → 3 steps, never skip Step 3:

1️⃣ Distance = value − a
2️⃣ Jumps = Distance ÷ d
3️⃣ n = Jumps + 1 ❗

a=4, d=6, value 88 → 84÷6=14 jumps → n=15

🚧 BOUNDARY — first to pass / last above a line

Do the Backward move with > or <, then check BOTH neighbours.

Check Tₙ AND the term next to it.
Landing exactly ON the line doesn't count!

"Exceed 91", T₁₅=91 exactly? Not enough → answer T₁₆

➕ EXPAND & ADD — two terms sum to a number

"T₃ + T₆ = 57" → write each as algebra, then add:

T₃ = a + 2d  (3−1=2)
T₆ = a + 5d  (6−1=5)
→ 2a + 7d = 57 → solve for a

d=5: 2a+35=57 → 2a=22 → a=11

🏁 Last move, every time: CHECK

Plug your answer back in. 5 seconds. It catches the +1 mistake every single time.
