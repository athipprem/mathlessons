⚖️ What If BOTH Pans Have a Mix?

Why learn this?

You already know balance-scale basics: heavier side goes down, level means equal, and you can trade "1 melon" for "6 grapes" if that's what one scale told you. But what happens when EACH pan has a MIX of two different fruits at once — like 2 apples + 1 banana on one side, and 1 apple + 3 bananas on the other? You can't just read off one item's weight directly anymore. You need a new trick: cancelling the parts that match, so only ONE item is left on each side. This exact skill shows up constantly in competition puzzles.

If the SAME item sits on BOTH pans, remove one from each side — the scale STAYS balanced.

The Big Idea — Cancel the Matching Items

Picture two people holding equally heavy bags in each hand. If you take ONE identical item away from BOTH of their left hands, their hands are still equally heavy — you just removed the same thing from both sides. A balance scale works exactly the same way.

Find an item on BOTH pans → remove ONE from each side → repeat → stop once one pan has only ONE type of item left.

⚠️ You must remove the SAME item, ONE at a time, from BOTH sides together. Never remove from just one side — that would break the balance.

Worked Example 1

Left pan: 2 apples + 1 banana. Right pan: 1 apple + 3 bananas. The scale balances. How many bananas weigh the same as 1 apple?

Step 1 — find an item on BOTH pans. "Apple" is on both (left has 2, right has 1). Cancel 1 apple from each side:
Left: 2 apples − 1 = 1 apple left, plus the 1 banana → 1 apple + 1 banana
Right: 1 apple − 1 = 0 apples left, plus the 3 bananas → 3 bananas
Step 2 — "banana" is now on BOTH pans too (left has 1, right has 3). Cancel 1 banana from each side:
Left: 1 banana − 1 = 0 bananas left, plus the 1 apple → 1 apple
Right: 3 bananas − 1 = 2 bananas
Step 3 — only ONE item type left on each side. Read off the ratio:
1 apple = 2 bananas

Worked Example 2 — A Bigger Start

Left pan: 3 apples + 2 bananas. Right pan: 2 apples + 5 bananas. The scale balances. How many bananas weigh the same as 1 apple?

Same method — there's just more to cancel before we get to one item on each side.

Cancel 2 apples from both sides (both have ≥2): Left → 1 apple+2 bananas. Right → 5 bananas.
Cancel 2 bananas from both sides (both have ≥2): Left → 1 apple. Right → 3 bananas.
1 apple = 3 bananas
It doesn't matter which matching item you cancel first — keep going until only ONE type is left on each side.

🗺️ The Plan

1Look at both pans. Find an item that appears on BOTH sides.
2Cancel ONE of that item from EACH side. The scale stays balanced.
3Repeat for every item that's still on both sides — one at a time, both sides together.
4Stop once ONE pan has only a single item type left (0 of anything else).
5Read off the ratio: "1 [item on the small side] = n [item on the other side]."
6Bonus: if you're told the real weight of one item, multiply to find the other's real weight.

⚠️ Only cancel items that appear on BOTH pans. Never touch an item that's on just one side.

📖 The Cancel Trick — in one line

Find an item on BOTH pans, cancel one from each side, repeat — until one pan has only ONE item type left.

This turns a mixed, confusing scale into a simple "1 item = n item" fact you can use.

🏆 You've got it when…

  • You spot the item on BOTH pans before touching anything
  • You cancel one at a time, from both sides together, never just one side
  • You stop exactly when one pan has a single item type left
