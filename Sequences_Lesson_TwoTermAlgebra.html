🪤 The Two-Term Trap

Here's a question type that looks easy — but almost everyone gets it wrong the first time:

In a sequence with d = 3, the 2nd term and the 6th term add up to 32.
Find the first term a.
❌ The guess-and-try approach

You might try: guess a = 5, list terms: 5, 8, 11, 14, 17, 20 → T₂+T₆ = 8+20 = 28. Too small. Try a = 6: T₂+T₆ = 9+23 = 32 ✓... but it took 2 guesses. What if the answer is a = 47? You'd guess forever.

✅ The algebra approach — always one step

We express both terms using the formula, then add them and solve. No guessing needed — ever.

💡 Also in this lesson: The Jump-Counting Fix

Many students lose marks on questions like "T₅=27, T₉=43, find T₁" because they miscalculate T₁.
In this lesson you'll learn the exact rule that prevents this mistake.

📐 The Express-and-Add Method

When two terms add up to a known value, expand both using the formula, then add and solve.

Step 1 — Express each term
Term Using Tₙ = a + (n−1)×d With d = 3
T₂ a + (2−1) × 3 = a + 3
T₆ a + (6−1) × 3 = a + 15
T₂ + T₆ = (a + 3) + (a + 15) = 2a + 18
Step 2 — Set equal to the given sum and solve
1 Set up 2a + 18 = 32 (T₂+T₆ = 32)
2 Subtract 2a = 32 − 18 = 14 remove constant
3 Divide a = 14 ÷ 2 = 7 a = 7 ✓
Key pattern: When you add two terms, the n-parts add too.
T₂ + T₆ = (a+3) + (a+15) = 2a + 18. The "18" comes from 3+15 = sum of (n−1)×d for each term.
🔢 The Jump-Counting Rule

When you know two terms and need to find d — or when working backwards to T₁ — count jumps, not term numbers.

Jumps from Tm to Tn = n − m
NOT n, NOT n−1 — it's always n minus m

📝 Worked Example 1 — Two-Term Sum
In a sequence with d = 3, the 2nd term and the 6th term add up to 32. Find a.
T₂ = a + (2−1)×3 = a + 3
T₆ = a + (6−1)×3 = a + 15
T₂ + T₆ = (a+3) + (a+15) = 2a + 18 = 32
2a = 32 − 18 = 14
a = 7 ✓   Check: T₂=10, T₆=22, sum=32 ✓
📝 Worked Example 2 — Find d, T₁, then Tₙ
In a sequence, T₅ = 27 and T₉ = 43. Find d and T₁.
Jumps from T₅ to T₉: 9 − 5 = 4 jumps
d = (43 − 27) ÷ 4 = 16 ÷ 4 = 4
Jumps from T₁ to T₅: 5 − 1 = 4 jumps
T₁ = T₅ − 4×d = 27 − 4×4 = 27 − 16 = 11
d = 4, T₁ = 11 ✓   Check: T₅=11+4×4=27 ✓
📝 Worked Example 3 — Two-step: find a first, then solve inequality
In a sequence with d = 5, the 6th term is 48. Which term first exceeds 100?
Step 1 — find a: T₆ = a + (6−1)×5 = a + 25 = 48 → a = 23
Step 2 — set up inequality: 23 + (n−1)×5 > 100
(n−1)×5 > 77 → n−1 > 15.4 → n ≥ 17
Answer: T₁₇ ✓   Check: T₁₇=23+80=103>100✓, T₁₆=23+75=98<100✓
Two-step rule: When a is not given directly, always find a from the given term first. Then solve the inequality.

🏆 All 5 Question Types — Decision Guide
Type What's given What to find Method
A a, d, n Tₙ Direct: Tₙ = a + (n−1)×d
B Two terms (Tₘ, Tₙ) d, T₁, and another term Jumps = n−m → d → T₁ using jumps back
C a, d First exceeding / last above zero Set up inequality → round correctly
D a, d, Tₙ value n (which term?) Reverse: n = (Tₙ − a) ÷ d + 1
E d, Tₘ + Tₙ = sum a (first term) Expand both → add → solve 2a + k = sum

Jumps from Tm to Tn = n − m
