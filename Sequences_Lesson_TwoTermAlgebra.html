🤔 A different kind of sequences question

So far, every question gave you a and d directly. But some questions hide the first term and tell you something else instead:

Example question:
In a sequence, d = 5.
The 1st term + the 3rd term = 36.
What is a (the 1st term)?

You are not told what T1 is. You are not told what T3 is. You only know they add up to 36.

To solve this, we use the Express-and-Add method: write each term as an algebra expression using a and d, then add them together and solve.
📋 How to express any term using a and d

Every term in an arithmetic sequence can be written with just a and d. Here are the first five terms:

T1 =a← the first term — no d yet
T2 =a + d← 1 jump of d from T1
T3 =a + 2d← 2 jumps of d from T1
T4 =a + 3d← 3 jumps of d from T1
T5 =a + 4d← 4 jumps of d from T1
⚠ The jump count = term number − 1
T3 = a + 2d  (not 3d). T5 = a + 4d  (not 5d). Count the arrows between T1 and the term — that is the number of d’s you add.

🔁 The Express-and-Add Method — Every Step

Problem: d = 5, T1 + T3 = 36. Find a.

Step 1 — Draw the jumps to see how many d’s each term has
T1
= a
→+d→
T2
= a+d
→+d→
T3
= a+2d

From T1 to T3: there are 2 arrows = 2 jumps. So T3 = a + 2d.

Step 2 — Write each term as a number expression (plug in d=5)
T1 =a← T1 is always just a
T3 =a + 2 × 5← 2 jumps, each of size d=5
T3 =a + 10← because 2 × 5 = 10
Step 3 — Add the two expressions together and solve
T1 + T3 = 36← given in the question
a + (a + 10) = 36← substitute T1=a and T3=a+10
a + a + 10 = 36← remove the brackets
2a + 10 = 36← a + a = 2a
2a = 36 − 10← subtract 10 from both sides
2a = 26← 36 − 10 = 26
a = 26 ÷ 2← divide both sides by 2
a = 13 ✓← 26 ÷ 2 = 13
Check: T1=13, T3=13+10=23    13+23 = 36 ✓
📌 The method in one sentence
1 Express each term using a and d  (count jumps, not position)
2 Add the two expressions together
3 Solve for a

✏ Worked Example — T1 + T5

A slightly harder example: the two terms are further apart. The method is exactly the same — just count the jumps carefully.

Example: d = 4, T1 + T5 = 44. Find a.
T1 = a  |  T5 = a + 4×4 = a + 16
Count the jumps from T1 to T5:
T1
→+d→
T2
→+d→
T3
→+d→
T4
→+d→
T5

4 arrows = 4 jumps. So T5 = a + 4d = a + 4×4 = a + 16.

T1 + T5 = 44← given
a + (a + 16) = 44← substitute T1=a, T5=a+16
a + a + 16 = 44← remove brackets
2a + 16 = 44← a + a = 2a
2a = 44 − 16← subtract 16 from both sides
2a = 28← 44 − 16 = 28
a = 28 ÷ 2← divide both sides by 2
a = 14 ✓← 28 ÷ 2 = 14
Check: T1=14, T5=14+16=30    14+30 = 44 ✓
⚠ What if neither term is T1?
If the question says T2 + T4 = ..., express both using a and d in the same way. T2=a+d, T4=a+3d. Add, simplify, solve.

📌 Quick Reference — Two-Term Algebra
Tp + Tq = [a+(p−1)d] + [a+(q−1)d]
When given d and the sum of two terms — find a:
1 Express each term: a + (jumps × d) — count arrows, not position
2 Add both expressions: will always give 2a + (some number)
3 Subtract the number, then divide by 2 to get a
ExampleExpressionsEquationAnswer
d=5, T1+T3=36a + (a+10)2a+10=36a=13
d=4, T1+T5=44a + (a+16)2a+16=44a=14
d=3, T2+T5=33(a+3) + (a+12)2a+15=33a=9
⚠ Remember: jump count = term number − 1
T3 = a + 2d. T5 = a + 4d. Always subtract 1 from the term number to get the number of d’s.
