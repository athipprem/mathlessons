🧩 The Missing Half of the Topic

You already own the middle trick — three or five numbers in a row, you go straight to sum ÷ count. But when there are two or four numbers, there is no single middle to land on. That's the part that tripped you up last time. Today you get the tool for it.

🔍 Count the numbers. Is it ODD (3, 5) or EVEN (2, 4)?

⭐ ODD count (3 or 5) — you already nailed this

middle = sum ÷ count, then step out. Reflex. No change.

🧮 EVEN count (2 or 4) — use the n-method

No single middle. Name the smallest n, build the others, add them up, solve. Trained today.

Four Numbers — Name the Smallest n

Four numbers in a row, each one more than the last. Call the smallest n:

nsmallest
n+1
n+2
n+3largest
add them: n + (n+1) + (n+2) + (n+3) = 4n + 6← four n's, and 1+2+3 = 6

Example: four consecutive numbers add to 58.

4n + 6 = 58
4n = 52 → n = 13← take 6 off, then ÷ 4
13, 14, 15, 16← check: 13+14+15+16 = 58 ✓

Two numbers work the same way: n + (n+1) = 2n + 1.

Consecutive EVEN or ODD — Step by 2

Even numbers (or odd numbers) in a row jump by 2, not 1. So from the smallest n:

n
n+2
n+4
n+6
add: n + (n+2) + (n+4) + (n+6) = 4n + 12← 2+4+6 = 12

Example: four consecutive EVEN numbers add to 84.

4n + 12 = 84 → 4n = 72 → n = 18
18, 20, 22, 24← all even ✓   18+20+22+24 = 84 ✓

Example: two consecutive numbers add to 37.

2n + 1 = 37 → 2n = 36 → n = 18 → 18, 19

💡 Sanity check: n must match the type. For "even numbers", n has to come out even. If you get a fraction or the wrong parity, re-check whether the step is +1 or +2.

Then Answer What They Asked

Once you have the four numbers, read the last line again — smallest, largest, or a sum of some of them.

Example A  Four consecutive numbers add to 50. Sum of the smallest and largest?

4n + 6 = 50 → n = 11 → 11, 12, 13, 14
smallest + largest = 11 + 14 = 25

Example B  Four consecutive EVEN numbers add to 44. Find the largest.

4n + 12 = 44 → n = 8 → 8, 10, 12, 14
largest = 14

Practice

Even count → name the smallest n, build, add, solve. Step +1 for plain numbers, +2 for even/odd. Then read the last line.

Q1.   Four consecutive integers add up to 62. What is the smallest one?
4n + 6 = 62 → 4n = 56 → n = 14 → 14,15,16,17
Q2.   Four consecutive EVEN numbers add up to 60. What is the largest one?
4n + 12 = 60 → 4n = 48 → n = 12 → 12,14,16,18
largest = 18
Q3.   Two consecutive integers add up to 39. What are the two numbers?
2n + 1 = 39 → 2n = 38 → n = 19 → 19, 20
Q4.   Four consecutive ODD numbers add up to 64. What is the largest one?
4n + 12 = 64 → 4n = 52 → n = 13 → 13,15,17,19
largest = 19
📖 The n-Method in Four Lines
Two numbers:n + (n+1) = 2n + 1 = sum. Four numbers:n + (n+1) + (n+2) + (n+3) = 4n + 6 = sum. Even / odd four:step +2 → 4n + 12 = sum. Solve & check:take the number off, ÷ by the n-count, list, add back to confirm.

🏆 You are ready when...

  • You see "four numbers" and write n, n+1, n+2, n+3 without pausing
  • You switch the step to +2 the moment it says even or odd
  • You never leave a four-number question blank again
