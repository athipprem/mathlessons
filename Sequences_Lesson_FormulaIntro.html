Why listing doesn't work 🚫

You have been finding sequence terms by writing them out one by one. Let's see why that method has a serious problem.

❌ Listing method on a big question:

Find the 50th term of the sequence: 3, 7, 11, 15, ...
3, 7, 11, 15, 19, 23, 27, 31, 35, 39, 43, 47, 51, 55, 59, 63, 67, 71, 75, 79 ...
(still going ...) 83, 87, 91, 95, 99, 103, 107, 111 ...
(keep writing ...) 115, 119, 123, 127, 131, 135, 139 ...
(almost there ...) 143, 147, 151, 155, 159, 163, 167, 171, 175, 179, 183, 187, 191, 195, 199 ← T₅₀

That was 50 terms to write. How long did it take? And what if the question asked for T₁₀₀?

⚡ The same question using the formula — 1 line:

T₅₀ = 3 + (50 − 1) × 4 = 3 + 49 × 4 = 3 + 196 = 199 ✓

The formula method works in one calculation — no matter how large the term number is. That's why we learn it.

Formula = 1 calculation. Listing = writing forever.
Works for T₅₀, T₁₀₀, T₅₀₀. Listing does not.

Meet the formula 🔬

Every arithmetic sequence follows this rule exactly. The formula has four parts — each part has a job.

Tn = a + ( n − 1) × d
🎯 Tₙ = the answer
the term you're finding
🌱 a = first term
the starting number
🔢 n = term number
which term you want
📈 d = common difference
how much it grows each step

For the sequence 3, 7, 11, 15, ... — let's name the parts:

First term (a)
The sequence starts at 3.
So a = 3.
Common difference (d)
Each step increases by 4 (7−3=4).
So d = 4.
💡 How to find d (the step size):

Subtract any term from the next term: d = T₂ − T₁ = T₃ − T₂, etc. If the sequence goes down, d is negative.

Always identify a and d BEFORE using the formula.
Write them down. a = ___ , d = ___ . Then substitute.

The 3-step method ⚡

Step 1
Write down a (first term) and d (common difference).
Step 2
Write the formula: Tn = a + (n − 1) × d. Substitute your values.
Step 3
Calculate step by step: brackets first → multiply → add. Write each line.

Worked Example 1 — Find T₁₂

Sequence: 7, 11, 15, 19, ... Find the 12th term.

StepWhat you doYour working
1Find a and da = 7, d = 4
2Write formula + substituteT₁₂ = 7 + (12 − 1) × 4
3aBrackets first= 7 + 11 × 4
3bMultiply= 7 + 44
3cAdd → answerT₁₂ = 51

Sequence: 8, 13, 18, 23, ... Find the 20th term.

StepWhat you doYour working

⚠ Write the steps first, then calculate.
Write: a = ___, d = ___, then Tn = a + (n−1) × d. This forces you to use the formula — not guess.

Lesson 1 summary 📋

Tₙ = a + (n − 1) × d
a = first term  |  d = common difference (how much it grows)  |  n = which term  |  Tₙ = the answer
📌
Always write a = ___ , d = ___ before substituting.
📌
Brackets come first: calculate (n − 1) before multiplying by d.
📌
If the sequence goes down, d is negative (e.g. d = −3).
📌
Write every line of working — the formula must be visible on paper.
