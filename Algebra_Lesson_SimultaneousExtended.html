📏 Type 1: Perimeter + Length/Width

The perimeter gives you L + W = half the perimeter. Then the length/width relationship gives you the second equation.

Perimeter = 2(L + W)  →  L + W = Perimeter ÷ 2
📋 Example

The perimeter of a rectangle is 40 cm. The length is 4 cm more than the width. Find the length and width.

1
L + W = 40 ÷ 2 = 20
2
L = W + 4, so W + 4 + W = 20 → 2W = 16 → W = 8 cm
3
L = 8 + 4 = 12 cm ✅   Check: perimeter = 2(12+8) = 40 ✓

🪙 Type 3: Mixed Coin Problems

Two types of coin (or note). Given: total number of coins AND total value → two equations, solve for both.

📋 Example

A piggy bank has 25 coins — only 5¢ and 25¢ coins. Total value is $2.45. How many 25¢ coins are there?

1
Let f = 5¢ coins, t = 25¢ coins.
f + t = 25 (total coins)
5f + 25t = 245 (total cents)
2
From eq1: f = 25 − t. Substitute: 5(25−t) + 25t = 245 → 125 − 5t + 25t = 245 → 20t = 120 → t = 6.
3
6 coins of 25¢ ✅   Check: f = 19, 5×19+25×6 = 95+150 = 245¢ = $2.45 ✓
Method shortcut: Multiply the count equation by the smaller coin value, then subtract from the total value equation to isolate the bigger coin.

Same as animal legs — but with vehicles and wheels. Two equations: total count + total wheels.

📋 Example

A shed has 12 vehicles — bikes (2 wheels) and tricycles (3 wheels). Total 28 wheels. How many tricycles?

b + t = 12 (vehicles)    2b + 3t = 28 (wheels)
2

You solved three-person in U13. Now the relationships use both multiplication and addition together.

1
Let Sam = S. Ben = 3S. Ali = S + 8.
2
S + 3S + S + 8 = 48 → 5S + 8 = 48 → 5S = 40 → S = $8
3
Ben = $24  ·  Ali = $16 ✅   Check: 8+24+16=48 ✓
