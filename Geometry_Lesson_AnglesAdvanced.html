The method is always the same
Write the angle rule → collect terms → solve for x → check. Every type works the same way.

Angles at a point = 360° 🔵

All angles meeting at a single point add up to 360° — think of a full circle.

a° + b° + c° + d° = 360°
Any number of angles around a single point always sum to 360°
Three angles meet at a point: 130°, 95°, and k°. Find k.
1
130 + 95 + k = 360
2
225 + k = 360 → k = 360 − 225 = 135°
✅ k = 135°

Quadrilateral + Algebra — finish what you started ⭐

You already know: all 4 angles in a quadrilateral sum to 360°. With algebra, just write that equation and solve.

A quadrilateral has angles x°, (2x − 5)°, (x + 15)°, and 90°. Find x and the largest angle.
1
Write angle sum: x + (2x−5) + (x+15) + 90 = 360
2
Collect: 4x + 100 = 360 → 4x = 260 → x = 65
3
Angles: 65°, 125°, 80°, 90°. Largest = 125°
4
Check: 65+125+80+90 = 360 ✓
✅ x = 65°, largest = 125°

Isosceles triangle + algebra — the one extra step ⭐⭐

You already know: isosceles → two base angles are equal. Use that fact first, then write the sum = 180° equation.

Triangle PQR has PQ = PR. Angle QPR = (2x + 10)°. Angle PQR = (3x + 5)°. Find x and all three angles.
1
PQ = PR → base angles equal → angle PRQ = (3x + 5)°
2
Write sum: (2x+10) + (3x+5) + (3x+5) = 180
3
Collect: 8x + 20 = 180 → 8x = 160 → x = 20
4
Angles: QPR = 50°, PQR = PRQ = 65°. Check: 50+65+65 = 180 ✓
✅ x = 20, angles: 50°, 65°, 65°
The isosceles shortcut
Equal sides → write the BASE angle expression TWICE in the equation. Then solve normally.

Summary — Advanced Angle Algebra 🚀

Angles at a point
All angles around one point = 360°. Missing angle = 360 − sum of others.
Quadrilateral + algebra
Sum of 4 angles = 360°. Write all 4 expressions, collect, solve. Always verify sum = 360.
Isosceles + algebra
Equal sides → write base angle TWICE. Sum of all 3 = 180°. Solve for x.
Always check!
Substitute x back into every angle. Verify the sum equals 180° or 360°.
Quad = 360° · Isosceles → base twice · Always check sum
