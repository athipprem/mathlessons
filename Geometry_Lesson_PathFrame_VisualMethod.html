✏️ The Draw-It-First Method

Before writing a single number — draw the shape. Here's the 3-step rule for every path problem:

1
Draw the outer rectangle. Write L and W on the outside edges.
2
Mark the path width on BOTH sides of each dimension — use small arrows or tick marks. This is why it's always ×2.
3
Write the new dimension on the inner shape: L ± 2p for each side.

VISUAL: Inner path — path reduces BOTH ends of each dimension

Inner area = (L − 2p) × (W − 2p)  ·  Path area = Outer − Inner

Each dimension shrinks by p on BOTH sides → always subtract 2p, never 1p

🟢 Inner Path — Worked Example

📋 Example

A rectangular garden is 36 m long and 22 m wide. A path 3 m wide runs inside all four edges. Find the area of the path.

1
Draw it: Outer = 36 × 22. Path is 3m wide → marks on BOTH sides of length (3+3=6m total), BOTH sides of width (3+3=6m total).
2
Inner dimensions: Length = 36 − 2×3 = 36 − 6 = 30 m. Width = 22 − 2×3 = 22 − 6 = 16 m.
3
Areas: Outer = 36 × 22 = 792 m². Inner = 30 × 16 = 480 m².
4
Path area = 792 − 480 = 312 m² ✅
⚠️ The trap: Some students subtract only 3 (not 2×3=6) from each dimension. If you draw the path on paper, you'll see it takes 3m from BOTH the left AND right side — that's where the ×2 comes from!

🔵 Outer Path — Worked Example

OUTER path: the path GROWS outward on all sides

Outer area = (L+2p) × (W+2p)  ·  Path = Outer − L×W

📋 Example

A field is 16 m long and 10 m wide. A path 3 m wide is built outside all four sides. Find the area of the path.

1
Outer dims: (16+6) × (10+6) = 22 × 16 = 352 m²
2
Inner (the field itself) = 16 × 10 = 160 m²
3
Path = 352 − 160 = 192 m² ✅

🖼️ Frame / Border — "Outer Dims Given" Trap

❌ U13 Q3 — What went wrong?

Q3 said: "A frame has outer dimensions 26 cm × 20 cm. Border 3 cm wide." The question ALREADY gives the outer size!

You added 3 cm to get bigger dims (32×26) and used those as outer — but 26×20 was already the outer! Never add to the given outer dims.

🎯 Frame Rule

Outer dims are GIVEN → they're the outer. Full stop.
Inner = (outer L − 2×border) × (outer W − 2×border)
Frame area = outer area − inner area

📋 Example — Frame

A picture frame has outer dimensions 50 cm × 34 cm. The frame border is 5 cm wide. Find the frame area.

1
Outer = 50 × 34 = 1700 cm² (given — don't change this!)
2
Inner opening = (50 − 10) × (34 − 10) = 40 × 24 = 960 cm²
3
Frame = 1700 − 960 = 740 cm² ✅
Practice 3 — Frame
A wooden frame has outer dimensions 44 cm × 30 cm. The frame is 3 cm wide on all sides. Find the frame area.
Inner = (44−6) × (30−6) = × =
Frame = 44×30 − inner = 1320 − =
Inner = 38 × 24 = 912 cm². Frame = 1320 − 912 = 408 cm² ✅

⬜ Square Paths — The ×3 Trap Fixed

❌ U13 Q4 — The ×3 error

Q4: Square 20m, path 3m inside. You subtracted 3+3+3=9 and got (20−9)²=121.
But there are only TWO sides: top and bottom. You only subtract 2×3=6.
Inner side = 20 − 6 = 14, not 11. Path = 400 − 196 = 204, not 121.

Visual check: Draw a square. The path goes along the TOP edge (−p) and the BOTTOM edge (−p). That's it — only two subtractions per dimension. Same for left and right. Always 2×p per dimension, even for squares.
📋 Example — Square Inner Path

A square courtyard has a side length of 22 m. A paved path 3 m wide runs inside all four edges. Find the area of the path.

1
Draw it: path takes 3m from top AND 3m from bottom. Inner side = 22 − 2×3 = 22 − 6 = 16 m.
2
Outer area = 22² = 484 m². Inner area = 16² = 256 m².
3
Path = 484 − 256 = 228 m² ✅

💰 Path + Cost (Two-Step)

Some questions ask how much it costs to pave the path. Two steps: find path area first, then multiply by cost per m².

📋 Example — Cost Question

A garden is 24 m long and 15 m wide. A path 2 m wide runs outside. Paving costs $4 per m². Total cost?

1
Outer = (24+4) × (15+4) = 28 × 19 = 532 m²
2
Inner = 24 × 15 = 360 m²
3
Path area = 532 − 360 = 172 m²
4
Cost = 172 × $4 = $688 ✅

📋 Cheat Sheet — 3 Types, 3 Rules

Inner Path
Inner = (L−2p) × (W−2p)  ·  Path = L×W − Inner
Outer Path
Outer = (L+2p) × (W+2p)  ·  Path = Outer − L×W
Frame
Outer given → Inner = (L−2b) × (W−2b)  ·  Frame = Outer − Inner
Square
Same rules — just one dimension: (side ± 2p)²  ·  Area = outer² − inner²

🎯 The 3 Things That Always Trip You Up

1. ×1 vs ×2: Draw it — you'll see BOTH sides. Always ×2.
2. Frame outer/inner: If outer is given, it's outer. Don't add anything.
3. Square: Same rule! Inner side = side − 2p. Always 2p, never 3p.
