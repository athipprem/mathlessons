What is an arithmetic sequence?

An arithmetic sequence is a list of numbers where you add the same amount each time. That amount is called the common difference (we write it as d).

How to Use the Formula

Three types of sequence questions — let’s work through each one.

Type A — Find a specific term

The sequence 3, 7, 11, 15, … What is the 20th term?
1Identify a and d. a = 3, d = 4 (difference between each pair)
2Apply the formula. T₂₀ = 3 + (20−1) × 4 = 3 + 19 × 4
3Calculate. 19 × 4 = 76. T₂₀ = 3 + 76 = 79
T₂₀ = 79 ✓

Type B — Use the nth-term formula

The nth term of a sequence is 5n − 2. Find T₃ + T₆.
1Substitute n = 3. T₃ = 5(3) − 2 = 15 − 2 = 13
2Substitute n = 6. T₆ = 5(6) − 2 = 30 − 2 = 28
3Add. T₃ + T₆ = 13 + 28 = 41
Sum = 41 ✓

Type C — Find the first term given other terms

In a sequence, T₄ = 22 and T₇ = 37. Find the first term.
1Find d. From T₄ to T₇ is 3 steps. T₇ − T₄ = 37 − 22 = 15. d = 15 ÷ 3 = 5
2Work back from T₄. T₄ = a + 3d = 22. So a = 22 − 3×5 = 22 − 15 = 7
3Check. Sequence: 7, 12, 17, 22, 27, 32, 37 ✓
First term = 7, d = 5 ✓
