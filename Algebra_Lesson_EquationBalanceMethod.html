Why you can't just guess 🚫

Some students try guess-and-check — pick a number, substitute it in, see if it works, then try again. Let's see why that approach breaks down.

❌ Guess-and-check on a hard equation:

Solve: 7n − 8 = 3n + 28
Try n = 5 → Left: 27, Right: 43 ✗
Try n = 8 → Left: 48, Right: 52 ✗
Try n = 9 → Left: 55, Right: 55 ✓ ... got lucky after 3 tries!

Now try: 5n + 6 = 2n + 60
Try n = 5 → Left: 31, Right: 70 ✗
Try n = 10 → Left: 56, Right: 80 ✗
Try n = 14 → Left: 76, Right: 88 ✗
Try n = 16 → Left: 86, Right: 92 ✗
Try n = 18 → Left: 96, Right: 96 ✓ ... took 5 tries!

What if the answer was n = 47? You could be guessing all day.

The algebraic method finds the answer in 3 steps every single time — no matter how large n is. That's why we learn it.

Algebra = guaranteed method. Guessing = luck.
A 3-step process that always works, even when n = 47 or n = 200.

Equations are balance scales ⚖️

An equation means both sides are exactly equal. The = sign is the pivot. To keep the scale balanced, whatever you do to one side you must do to the other.

We use colour coding in every step:

🔵 n-terms (blue)
3n, 5n, 2n — anything with n in it
🔴 number-terms (red)
4, 22, −5 — plain numbers
The Golden Rule
Whatever you do to one side — do exactly the same to the other side.

The 3-step solving ladder 🪜

Every simple equation (n on one side only) is solved with the same 3 steps. Follow the ladder, top to bottom.

Step 1 — Expand any brackets
If there are brackets, multiply them out first.
e.g. 2(n + 3) → 2n + 6
Step 2 — Move the red number to the right
If it's +, subtract it from both sides.
If it's −, add it to both sides.
Step 3 — Divide both sides to find n
Divide both sides by the coefficient of n (the number in front of it).

Example — Solve: 5n + 2 = 27

StepEquationAction
Start5n + 2 = 27Write it out
Step 25n = 27 − 2Subtract 2 from both sides
Simplify5n = 2527 − 2 = 25
Step 3n = 25 ÷ 5Divide both sides by 5
Answer✅ n = 5  |  Check: 5×5 + 2 = 27 ✓

Example — Solve: 3n − 7 = 11

StepEquationAction
Start3n − 7 = 11Write it out
Step 23n = 11 + 7Add 7 to both sides (−7 → +7)
Simplify3n = 1811 + 7 = 18
Step 3n = 18 ÷ 3Divide both sides by 3
Answer✅ n = 6  |  Check: 3×6 − 7 = 11 ✓

Brackets: expand first 🔣

When you see brackets, always expand first before doing Steps 2 and 3.

Example — Solve: 4(n + 2) = 28

StepEquationAction
Step 14n + 8 = 28Expand: 4×n + 4×2
Step 24n = 28 − 8Subtract 8 from both sides
Simplify4n = 2028 − 8 = 20
Step 3n = 20 ÷ 4Divide both sides by 4
Answer✅ n = 5  |  Check: 4×(5+2) = 28 ✓
