⚠️ What Happened in U11 Q5?

U11 test: "A rectangular field is 30 m long and 20 m wide. A path 2 m wide runs along the outside. What is the total area of the path?"

❌ What went wrong:

Outer dimensions used: (30+2) × (20+2) = 32 × 22 = 704
Path area = 704 − 600 = 104 — but this is wrong!

The path goes around ALL 4 sides. So the length gains 2m on the LEFT and 2m on the RIGHT = +4m total. Same for width.

✅ Correct approach:

Outer: (30 + 2×2) × (20 + 2×2) = 34 × 24 = 816
Path = 816 − 600 = 216 m²

💡 This lesson will make sure that never happens again. One rule, locked in for good.

📦 Inside Path (Frame / Border)

When a path or border runs along the inside of a rectangle — like a picture frame or carpet border.

Inner area = (L − 2p) × (W − 2p)
Frame area = Outer area − Inner area

Where p = path/border width. Each dimension loses 2p because the path cuts in from both sides.

Example — Garden with inside path

A garden is 10 m × 6 m. A path 1 m wide runs inside all four edges. Find the area of the path.

1
Outer (full garden): 10 × 6 = 60 m²
2
Inner (grass): (10 − 2) × (6 − 2) = 8 × 4 = 32 m²
3
Path = 60 − 32 = 28 m²

🌿 Outside Path

When a path surrounds the outside of a rectangle — like a pavement around a building or a track around a field.

Outer area = (L + 2p) × (W + 2p)
Path area = Outer area − Inner area

🔑 THE RULE — Never Forget This

Outside path → each dimension gets + 2 × path width
(NOT + p, because the path adds p on BOTH sides)

Example — Pool with outside path

A pool is 14 m × 8 m. A path 2 m wide surrounds it on all sides. Find the path area.

1
Inner (pool): 14 × 8 = 112 m²
2
Outer: (14 + 4) × (8 + 4) = 18 × 12 = 216 m²
3
Path = 216 − 112 = 104 m²

⚖️ Inside vs Outside — Side by Side

Inside Path

Keywords: carpet, border inside, frame inside, leaves gap

Dimensions shrink: L − 2p, W − 2p

Inner area = (L−2p)(W−2p)

Outside Path

Keywords: surrounds, runs outside, track around, pavement around

Dimensions grow: L + 2p, W + 2p

Outer area = (L+2p)(W+2p)

💡 In both cases: Frame/Path area = bigger area − smaller area. Always subtract.
⚠️ Common mistake: Using +p or −p instead of +2p or −2p. The path is on BOTH sides of each dimension — always multiply by 2.

A rectangular garden is 20 m long and 15 m wide. A path 2 m wide runs along the inside of all four edges. What is the area of the path?

1

🔀 Mixed Practice — Identify First!

Before calculating: is the path inside or outside? Then apply the correct formula.

Q1 — Inside or Outside?

A rectangle is 12 m × 8 m. A path 1 m wide runs inside all four edges. What is the area of the path?

Inside path. Inner = (12−2)×(8−2) = 10×6 = 60. Path = 96−60 = 36 m² ✓
Q2 — Inside or Outside?

A rectangle is 10 m × 6 m. A path 2 m wide surrounds the outside. What is the area of the path?

Outside path. Outer = (10+4)×(6+4) = 14×10 = 140. Path = 140−60 = 80 m² ✓

🎉 Locked In!

🔑 The One Rule

Outside path → each dimension gets +2×path width
Inside path → each dimension gets −2×path width

Path area = bigger area − smaller area

1
Read: Is the path inside or outside?
2
Calculate: Both areas (bigger and smaller)
3
Subtract: Path = bigger − smaller
4
Check: Path area must be less than total area
🏆 In the test — write "outer = (L+2p)(W+2p)" before calculating. Show the formula explicitly so you don't accidentally use +p.
