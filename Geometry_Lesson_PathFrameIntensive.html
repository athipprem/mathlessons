⚠️ What Went Wrong in Unit 12?

In Unit 12, three path questions went wrong — Q6, Q7, and Q9. Every single one had the same mistake:

❌ The Error — Used ×1 instead of ×2

Q6: inner path — subtracted the path width ONCE from each dimension instead of TWICE.
Got 13×7 = 91 m². Correct answer: (14−2)×(8−2) = 12×6 = 72 m²

❌ Q7 & Q9 — Same root cause

Q7: applied the outside formula when the question asked for the inside path.
Q9: added the path width once per side instead of twice (once on each end).

💡 The path goes along ALL 4 sides. So each dimension changes by 2p — once on each end. This lesson locks that in permanently.

🔑 The ONE Rule — Always ×2

Every path goes along BOTH ends of every dimension

Inside path → each dimension loses 2p (p from each end)
Outside path → each dimension gains 2p (p on each end)

INNER
Inner area = (L − 2p) × (W − 2p)
Path area = Outer − Inner
OUTER
Outer area = (L + 2p) × (W + 2p)
Path area = Outer − Inner (original)
FRAME
Frame area = Outer − Inner opening
Inner opening = (L − 2b) × (W − 2b)
🚨 Never subtract or add p just once. The path has TWO ends on every side. Always 2p.

📦 Inner Path — Worked Example

Example — Room with inside carpet border

A room is 20 m × 12 m. A carpet path 2 m wide runs inside all four walls. Find the area of the path.

1
Full room: 20 × 12 = 240 m²
2
Inner (uncarpeted): (20 − 2×2) × (12 − 2×2) = 16 × 8 = 128 m²
3
Path = 240 − 128 = 112 m²
✅ Key step: 2×2 = 4. Subtract 4 from EACH dimension. Both ends of the 20m get 2m, both ends of the 12m get 2m.

🔲 Outer Path — Worked Example

Example — Footpath around a pond

A rectangular pond is 14 m × 8 m. A concrete path 3 m wide is built all around the outside. Find the area of the path.

1
Outer (pond + path): (14 + 2×3) × (8 + 2×3) = 20 × 14 = 280 m²
2
Inner (pond only): 14 × 8 = 112 m²
3
Path = 280 − 112 = 168 m²
✅ Key step: 2×3 = 6. Add 6 to EACH dimension. The path extends 3m on both sides of the 14m, and 3m on both sides of the 8m.

🖼️ Frame & Border — Worked Example

Example — Photo frame area

A photo frame has outer dimensions 18 cm × 14 cm. The wooden border is 2 cm wide all around. Find the area of the wooden frame.

1
Outer (total frame): 18 × 14 = 252 cm²
2
Opening (photo): (18 − 2×2) × (14 − 2×2) = 14 × 10 = 140 cm²
3
Frame = 252 − 140 = 112 cm²
💡 A frame IS an inside path! The border cuts into both ends of the length and both ends of the width.

💰 The Twist — Cost & Tiles

Sometimes the question doesn't just ask for the path area — it asks for a cost or the number of tiles. Same method, just one more step.

Example — Cost of tiling a path

A room is 30 m × 20 m. A path 3 m wide runs inside. Tiles cost $4 per m². Find the total cost.

1
Inner area: (30−6)×(20−6) = 24×14 = 336 m²
2
Path area = 30×20 − 336 = 600 − 336 = 264 m²
3
Cost = 264 × $4 = $1,056
Example — Number of tiles needed

A garden is 34 m × 26 m. A path 4 m wide runs inside. Each tile covers 2 m². How many tiles?

1
Inner: (34−8)×(26−8) = 26×18 = 468 m²
2
Path = 34×26 − 468 = 884 − 468 = 416 m²
3
Tiles = 416 ÷ 2 = 208 tiles

🔍 Error Spotter — Find the Mistake

Two students solved the same problem. One is wrong. Can you spot the mistake?

Problem: A park is 18 m × 12 m. A path 3 m wide runs inside. Find the path area.

Student A

Inner = (18−3)×(12−3) = 15×9 = 135
Path = 216−135 = 81 m²

Student B

Inner = (18−6)×(12−6) = 12×6 = 72
Path = 216−72 = 144 m²

✅ Student B is correct! Student A only subtracted the path width ONCE from each dimension (3 instead of 6). The path cuts in from both ends: L loses 3m on the left AND 3m on the right = −6m total. Always ×2!
📌 Before every path question — write: "Each dimension changes by 2p" at the top of your working.

📋 Your Path & Frame Cheat Sheet

INNER
(L − 2p) × (W − 2p) = inner area
Path area = L×W − inner
OUTER
(L + 2p) × (W + 2p) = outer total
Path area = outer − L×W
FRAME
Outer − (L − 2b) × (W − 2b) = frame
b = border width
🚨 THE GOLDEN RULE: Path width ALWAYS multiplied by 2. No exceptions.
