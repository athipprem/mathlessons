You Already Know This!

You already use the gap method when you find d. Quick reminder:

T₄ = 22,  T₈ = 38
Gaps between T₄ and T₈ = 8 − 4 = 4← count the jumps between the two positions
d = (38 − 22) ÷ 4 = 4← total distance ÷ number of jumps

Today you use the same idea — but in reverse:

Distance = 78−3 = 75. Each jump = 5. Jumps = 75÷5 = 15. Term = 15+1 = T₁₆.

The 3-Step Rule

Use these three steps every time you need to find n:

1
Distance = Tₙ − a  How far from start to target?
2
Jumps = Distance ÷ d  How many steps to get there?
3
n = Jumps + 1  Add 1 because T₁ is step 1, not step 0

🤔 Why do we add +1?

If you took 0 jumps, you are still at T₁. Not T₀. So the term number is always one more than the jumps.

0 jumps → T₁← already at term 1 before any jump
1 jump → T₂← one jump past the start
15 jumps → T₁₆← 15 + 1 = term 16

🔗 How the 3 steps connect to the formula

The formula Tₙ = a + (n−1)×d rearranges into exactly the 3 steps:

Tₙ = a + (n−1) × d← standard formula
Tₙ − a = (n−1) × d← Distance = Jumps × step size
(Tₙ − a) ÷ d = n − 1← Jumps = Distance ÷ step size
n = (Tₙ − a) ÷ d + 1← n = Jumps + 1

You do not need to memorise the rearranged form — just remember Distance → Jumps → n!

Worked Examples

Example 1  a = 5, d = 6, Tₙ = 47. Find n.

Step 1: Distance = 47 − 5 = 42← Tₙ minus a (how far from start to 47)
Step 2: Jumps = 42 ÷ 6 = 7← distance ÷ d (how many steps of size 6)
Step 3: n = 7 + 1 = 8← jumps + 1 (started counting from term 1)
✓ Check: T₈ = 5 + 7 × 6 = 5 + 42 = 47 ✓← plug n back in to verify

Example 2  a = 9, d = 5, Tₙ = 79. Find n.

Step 1: Distance = 79 − 9 = 70← Tₙ minus a
Step 2: Jumps = 70 ÷ 5 = 14← distance ÷ d
Step 3: n = 14 + 1 = 15← jumps + 1
✓ Check: T₁₅ = 9 + 14 × 5 = 9 + 70 = 79 ✓← always check!

📌 Two things to watch out for

  • Distance ÷ d must be a whole number. If it is not, recheck your subtraction.
  • Always substitute n back into Tₙ = a + (n−1)×d to verify. This takes 5 seconds and catches mistakes.

Practice — Find n

Apply the 3 steps: Distance → Jumps → n = Jumps + 1. Always check your answer.
