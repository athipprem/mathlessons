Part 1 — Inequality Rounding: the one rule 📏

Some ISA questions say: "The sequence is 5, 8, 11, 14 … Which term is the first one below 100?"

How to set it up
Write Tₙ = 5 + (n−1)×3
Set Tₙ < 100 → 5 + (n−1)×3 < 100
Solve: (n−1)×3 < 95 → n−1 < 31.67 → n < 32.67
⚠ The U18 error — and the fix

In U18 Q5 you got n > 8.5 and wrote T₈. That's wrong — T₈ would make n > 8.5 FALSE (8 is not greater than 8.5).

The rule:

n < 32.67 → first whole number is T₃₂
n > 8.5 → first whole number is T₉
Always take the first whole number that SATISFIES the inequality

1

2

3

Example 2: Sequence 100, 93, 86 … Which term is the first one below zero?
1
Tₙ = 100 + (n−1)×(−7) = 100 − 7(n−1). Set Tₙ < 0 → 100 − 7(n−1) < 0
2
7(n−1) > 100 → n−1 > 14.29 → n > 15.29
3
First whole number greater than 15.29 is 16
✅ Answer: T₁₆ = 100 − 15×7 = 100 − 105 = −5
Check: always verify your answer!
Plug your term back in. If T₁₆ = −5 (below zero ✓) and T₁₅ = 2 (not below zero ✓) — you got the first one.

Part 2 — Two-Conditions: it's just algebra! 🧮

In U18 Q10 you were given: T₄ + T₁₀ = 54, and d = 3. Find T₁.
You left it blank — but watch how simple this is.

Write each term using the formula
T₄ = a + 3d   (that's 3 jumps from T₁)
T₁₀ = a + 9d  (that's 9 jumps from T₁)
Add them together
T₄ + T₁₀ = (a + 3d) + (a + 9d) = 2a + 12d
Substitute d = 3 and solve
2a + 12(3) = 54
2a + 36 = 54
2a = 18 → a = 9
💡 You already know how to do this!
1
Write T₄ and T₁₀ as expressions in a and d — like you write algebra unknowns.
2
Add them and simplify — collect the a terms (2a) and d terms (12d).
3
Put in the given d value, then solve for a. It's exactly the same as SimEq, just with one equation.

Worked examples — Two Conditions 🔢

Example A: T₃ + T₇ = 40, d = 4. Find T₁ and T₁₂.
1
T₃ = a + 2d, T₇ = a + 6d → sum = 2a + 8d = 40
2
Sub d = 4: 2a + 32 = 40 → 2a = 8 → a = 4
3
T₁₂ = 4 + 11×4 = 4 + 44 = 48
✅ T₁ = 4 · T₁₂ = 48
Example B: T₂ + T₆ = 32 (no d given — solve for both a and d!).
1
T₂ = a + d, T₆ = a + 5d → sum = 2a + 6d = 32 → a + 3d = 16
2
This gives one equation, two unknowns. A second condition is needed. (ISA always gives two facts for two unknowns.)
💡 If you get one equation + two unknowns, look for the second fact in the question!
⚠ Pattern to watch for

T₄ + T₁₀: both have (n−1) jumps → 3 + 9 = 12d. The d coefficient is always the sum of (n−1) values for both terms.
Quick check: T₄ + T₁₀ → 3 + 9 = 12 → coefficient of d is 12.
