🪙 List It, Then Check It

Why learn this?

You already know how to LIST every possible combination of coins that add up to a target amount. You also already know how to ARRANGE a set of digits into different numbers, and you already know the divisibility rules (÷2, ÷5, and more). This unit combines those two skills with one new twist: sometimes a listing question comes with an extra RULE attached — "at least one of each," "no more than 3," or "must be divisible by 5." Miss the rule, and you'll count combinations that don't actually count, or arrangements that don't actually work.

Where this shows up

Competition papers love this combo: "How many ways can you make ฿X using these two coins, if you must use at least one of each?" or "How many 4-digit numbers can you make from these digits that are divisible by 2?" Both are really the SAME idea — list your candidates, then cross out any that break the rule.

List every candidate. Check EVERY one against the rule. Only count the survivors.

🗺️ Two Skills, One Big Idea

Today has two parts. Both use the SAME big idea — list first, then filter by the rule — just on different kinds of questions.

AConstrained coin listing: given coin values and a target amount, list every combination that adds up correctly — then cross out any that break an extra rule (like "at least one of each" or "no more than 3").
BDivisibility arrangements: given a set of digits, count how many arrangements form a number that satisfies a divisibility rule — using the rule to work out WHICH digit can go last, before you even start listing.

⚠️ In both parts, the rule isn't a trap — it's a tool. Once you know the rule, it actually makes the list SHORTER and the question EASIER, not harder.

Part A — Worked Example

A donation box collects ฿50 using only ฿5 and ฿10 coins, with at least one of each coin. How many different combinations of coins could be inside?

Sweep the BIGGER coin from 1 upward. For each amount, check the leftover divides evenly.
Step 1 — sweep the ฿10 coin, starting at 1 (the rule says at least one):
1 × ฿10 = ฿10 → leftover ฿40 ÷ ฿5 = 8 ✓ → (8 fives, 1 ten)
2 × ฿10 = ฿20 → leftover ฿30 ÷ ฿5 = 6 ✓ → (6 fives, 2 tens)
3 × ฿10 = ฿30 → leftover ฿20 ÷ ฿5 = 4 ✓ → (4 fives, 3 tens)
4 × ฿10 = ฿40 → leftover ฿10 ÷ ฿5 = 2 ✓ → (2 fives, 4 tens)
5 × ฿10 = ฿50 → leftover ฿0 ÷ ฿5 = 0 ✗ — that's ZERO ฿5 coins, breaks "at least one of each"!
Step 2 — count only the survivors:
4 different combinations

⚠️ Without checking the rule, it looks like there are 5 combinations. The rule removes exactly one of them — the one using ZERO ฿5 coins. Always check EVERY row, not just count the rows.

💡 The Shortcut — Fix The Last Digit FIRST

Listing all 6 and checking each one works — but with 5 or 6 digits, that list gets huge fast (5 digits = 120 arrangements!). Here's the shortcut: use the rule to figure out which digit(s) are ALLOWED to go last, before you list anything.

Using the digits 1, 2, 3, 4, 5 (each exactly once), how many different 5-digit numbers can be formed that are divisible by 5?

Divisible by 5 → last digit must be 0 or 5
Step 1 — which digits are allowed last? Only 5 (no 0 in this digit set). Just ONE choice.
Step 2 — fix 5 in the last spot. What's left? 1, 2, 3, 4 — four digits, to arrange in the first four spots.
Step 3 — count the arrangements of what's left: 4! = 4×3×2×1 = 24
24 different numbers

⚠️ You didn't need to write out all 120 arrangements and check each one — fixing the last digit FIRST shrinks a huge listing job into one factorial.

1) Find which digit(s) can legally go last. 2) Fix one there. 3) Count arrangements of the rest with a factorial. 4) If more than one digit could go last, do this for EACH one and ADD the totals.

🗺️ The Full Checklist

Part A — Constrained Coin Listing

1Sweep the BIGGER coin from its lowest allowed count upward.
2For each amount, check: does the leftover divide EVENLY by the smaller coin?
3If yes — check the EXTRA rule too (at least how many? no more than how many?). Cross it out if it breaks the rule.
4Count only the survivors.

Part B — Divisibility Arrangements

1What's the rule asking for — ÷2 (last digit even) or ÷5 (last digit 0 or 5)?
2List EVERY digit in your set that's allowed to go last. Is there 0? 1? Several?
3If NONE of your digits work — the answer is 0. Don't try to list arrangements that can't exist!
4For each allowed last digit, fix it and count the arrangements of the rest with a factorial.
5If more than one digit is allowed last, ADD the totals together.

⚠️ Step 3 of Part B matters a lot: always check FIRST whether a valid last digit even exists, before you start counting anything.

📖 Today's Big Idea

List every candidate, then check EVERY one against the rule — whether the rule is "at least one of each" or a divisibility rule. Cross out anything that breaks it. Only count the survivors.

🏆 You've got it when…

  • You sweep the bigger coin methodically, checking every leftover for even division
  • You never forget the EXTRA rule — it's not optional, it's part of the question
  • Before counting digit arrangements, you first work out which digits are even ALLOWED to go last
  • If no digit works for the rule, you confidently write 0 instead of guessing

Both parts use the exact same habit: list carefully, check every candidate against the rule, count only what survives. That habit works on almost any counting question you'll ever see.
