📝 Count Every One — Miss None

Why learn this?

"How many ways can I pay 10 baht?" "How many different outfits from these shirts and shorts?" "How many 2-digit numbers add up to 7?" When you answer by jumping around randomly, you forget some and count others twice. The fix is simple: go in a fixed order and write a tidy list. Then you can be sure you got them all — which is exactly what wins contest marks.

Go in ORDER. Write a list or table. Then nothing is missed and nothing repeats.

List in a Fixed Order

How many 2-digit numbers have digits that add up to 4?

Go through the tens digit in order: 1, then 2, then 3, then 4. For each, the units digit is whatever is left to reach 4.

4040
Going in order → 4 numbers: 13, 22, 31, 40

Because we marched the tens digit up one at a time, we know we did not skip any and did not write the same one twice.

Fix One Thing, Vary the Rest

When there are many choices, fix one thing first and list the rest. Example: ways to pay 6¢ using 1¢ and 2¢ coins.

Fix the number of 2¢ coins, from most to fewest. The 1¢ coins just fill the gap:

2¢ coins1¢ coinsTotal
306¢
226¢
146¢
066¢
4 ways — because we stepped the 2¢ coins down in order

🗺️ The Plan

1Pick something to go in order — the tens digit, the number of big coins, the first letter…
2March it up (or down) one step at a time. For each step, write what fits.
3Write a tidy list or table so you can see you have them all.
4Check the FULL range. If it says "from 1", do not forget the single-digit answers (like 5) or a 0. Count to the very end too.

⚠️ The most common mistake: forgetting the single-digit case when the range starts at 1. "Numbers from 1 to 30 with digit sum 5" — the number 5 itself counts!

Worked Example

How many whole numbers from 1 to 25 have a digit sum of 4?

Check the full range first: it starts at 1, so single-digit numbers can count.
Single-digit: 4 (digit sum 4) ✓
Now go through the tens in order, units makes 4:
tens 1 → 13 (1+3=4) ✓
tens 2 → 22 (2+2=4) ✓
Stop at 25 — the next, 31, is past 25.
List: 4, 13, 22
3 numbers

⚠️ If you forgot the single-digit 4, you would answer 2 — the classic slip. Always sweep from the very start of the range.

Fix the tens digit, list the units 1,2,3:
11,12,13 / 21,22,23 / 31,32,33.
3 rows × 3 = 9.
9 numbers
P3.  How many ways can you pay 7¢ using only 1¢ and 5¢ coins?
Fix the number of 5¢ coins:
one 5¢ + two 1¢ = 7¢ ✓
zero 5¢ + seven 1¢ = 7¢ ✓
2 ways
P4.  How many whole numbers from 1 to 20 have a digit sum of 4?
Range starts at 1 → check single digits.
Single-digit: 4 ✓
Two-digit up to 20: 13 (1+3=4) ✓. 22 is past 20.
List: 4, 13.
2 numbers
📖 Systematic Listing — in one line

Pick something to go in order, march it step by step, write a tidy list, and sweep the FULL range.

Biggest trap: forgetting the single-digit number when the range starts at 1.

🏆 You've got it when…

  • You always choose an order (tens digit, number of big coins, first letter) instead of guessing
  • You write the list/table so you can see none are missed or repeated
  • You remember the single-digit and end-of-range cases

You now have both counting tools: figure counting and systematic listing. Ready for the test!
