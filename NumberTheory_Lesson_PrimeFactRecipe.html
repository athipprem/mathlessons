Today is different. No drill, no method first. We start with one question: what IS a prime number?

The Building Block

A prime number can't be split into equal groups.

Try to share 7 sweets equally between friends (not counting 1 friend or 7 friends). Can you do it?

No. 7 only divides evenly by 1 and itself. That's a prime.

Now try 6 sweets. Can you split equally?

Yes — 2 groups of 3, or 3 groups of 2. So 6 is not prime — it can be broken down.

Prime number = only divisible by 1 and itself. Can't be broken down further.
Not prime = has at least one other factor. Can be split.

The Big Idea

Every number has a secret recipe made of primes.

Think of primes like Lego bricks. Every number you can think of is built by multiplying a set of these prime bricks together.

The New Habit

When you see a big number — immediately start a tree.

The only reason the last 5 tests went blank is you didn't start. The maths isn't hard — you just proved that. The habit is: pencil touches paper the moment you see the number.

See: "Factorise 72"
→ Pencil moves. Write 72 at the top.
→ Pick any split you know: 72 = 8 × 9
→ Keep splitting. Done.

You don't need to see the whole tree before you start. Just write the number and pick any split. The tree builds itself.

You already know: 2×2=4, 3×3=9, 2×4=8, 4×4=16
That's all you need to start any factor tree.
