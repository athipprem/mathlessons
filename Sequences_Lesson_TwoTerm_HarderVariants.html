The Secret of the (n−1) Coefficient

When two terms add up to a known value, you need to expand each term as a formula first. The key rule is:

📖 Golden Rule: Tₙ = a + (n−1) × d

The coefficient of d is (n−1) — always ONE LESS than the term number.

  • T₁ = a + 0d  →  coefficient = 1−1 = 0
  • T₂ = a + 1d  →  coefficient = 2−1 = 1
  • T₃ = a + 2d  →  coefficient = 3−1 = 2
  • T₄ = a + 3d  →  coefficient = 4−1 = 3

❌ The Most Common Error

Students often write T₃ = a + 3d instead of T₃ = a + 2d. This is the same off-by-one error as forgetting +1 in Find n — they are connected!

❌ Wrong

T₃ = a + 3d
T₆ = a + 6d

✅ Correct

T₃ = a + 2d
T₆ = a + 5d

⚠ Orange rows (T₃, T₆) and green rows (T₅) are the ones that appear most in harder questions. Learn their coefficients.

How to Find the Sum T₃ + T₆ Step by Step

1
Expand each term using the table: T₃ = a+2d, T₆ = a+5d
2
Add them: (a+2d) + (a+5d) = 2a + 7d
3
Substitute d (it is usually given): 2a + 7 × d = total value
4
Solve for a: 2a = total − (7d), then a = result ÷ 2
5
Verify: check T₃ + T₆ = given total

Worked Examples

Example 1  T₃ + T₅ = 56, d = 4. Find a.

Expand: T₃ = a + 2d = a + 2(4) = a + 8← coefficient = 3−1 = 2
Expand: T₅ = a + 4d = a + 4(4) = a + 16← coefficient = 5−1 = 4
Sum: (a+8) + (a+16) = 56
2a + 24 = 56
2a = 32 → a = 16
✓ Check: T₃ = 16+8 = 24, T₅ = 16+16 = 32. Sum = 56 ✓

Example 2  T₃ + T₆ = 63, d = 3. Find a.

Expand: T₃ = a + 2(3) = a + 6← coefficient 2
Expand: T₆ = a + 5(3) = a + 15← coefficient 5
Sum: 2a + 21 = 63
2a = 42 → a = 21
✓ Check: T₃ = 27, T₆ = 36. Sum = 63 ✓

Example 3  T₄ + T₇ = 86, d = 6. Find a.

Expand: T₄ = a + 3(6) = a + 18← coefficient = 4−1 = 3
Expand: T₇ = a + 6(6) = a + 36← coefficient = 7−1 = 6
Sum: 2a + 54 = 86
2a = 32 → a = 16
✓ Check: T₄ = 34, T₇ = 52. Sum = 86 ✓

📌 Pattern You Can Use

When you add Tₚ + Tₘ:

  • Add the two d-coefficients: (p−1) + (q−1) = p + q − 2
  • The sum always = 2a + (p+q−2)d

E.g. T₃ + T₆: coefficients 2+5 = 7. Sum = 2a + 7d.

Compound Type: Find a, Then Find Tₙ

Some questions ask you to find a first, then use it to find another term. This is two steps, but each step is something you already know.

Worked Example: Two Steps

T₃ + T₅ = 52, d = 3. Find a. Then find T₁₂.

Step 1: Find a
T₃ = a + 2(3) = a + 6
T₅ = a + 4(3) = a + 12
2a + 18 = 52 → 2a = 34 → a = 17
Step 2: Find T₁₂ using the formula
T₁₂ = a + (12−1)d = 17 + 11×3 = 17 + 33 = 50← coefficient = 12−1 = 11
✓ Check: T₃ = 23, T₅ = 29. Sum = 52 ✓

💡 Test Strategy for Compound Questions

  1. Label the two given terms. Write Tₚ = a+(p−1)d and Tₘ = a+(q−1)d.
  2. Add them → 2a + (sum of coefficients) = given total. Solve for a.
  3. Use Tₙ = a + (n−1)×d with your found a to compute the asked term.
  4. Always verify by checking the original two-term sum.

➕ Expand & Add
Q1.   T₃ + T₅ = 72, d = 5. Find a.
T₃ = a+2d = a+10   T₅ = a+4d = a+20
Sum: 2a + 30 = 72 → 2a = 42 → a = 21
Check: T₃=31, T₅=41. 31+41=72 ✓
➕ Expand & Add
Q2.   T₄ + T₆ = 68, d = 5. Find a.
T₄ = a+3d = a+15   T₆ = a+5d = a+25
Sum: 2a + 40 = 68 → 2a = 28 → a = 14
Check: T₄=29, T₆=39. 29+39=68 ✓
➕ Expand & Add
Q3.   T₃ + T₆ = 69, d = 5. Find a.
T₃ = a+2(5) = a+10   T₆ = a+5(5) = a+25
Sum: 2a + 35 = 69 → 2a = 34 → a = 17
Check: T₃=27, T₆=42. 27+42=69 ✓
➕ Expand & Add then ➡️ Forward
Q4.   T₃ + T₅ = 76, d = 4. Find a first. Then find T₁₂.
T₃ = a+2(4)=a+8   T₅ = a+4(4)=a+16
2a + 24 = 76 → 2a = 52 → a = 26
T₁₂ = 26 + 11×4 = 26 + 44 = 70
Check sum: T₃=34, T₅=42. 34+42=76 ✓

🔁 Going backwards: if you know a middle term like T₅, then a = T₅ − 4d — 4 jumps back, NOT 5. Same (n−1) rule, just in reverse!

🔎 Find a first
Q5.   The 5th term of a sequence is 43 and d = 7. Find T₁.
Write: T₅ = a + (5−1)×d = a + 4d← coefficient = 5−1 = 4, NOT 5
a + 4×7 = 43 → a + 28 = 43 → a = 15
Check: 15, 22, 29, 36, 43 — T₅ = 43 ✓
⚠ Using a+5d gives a = 8 — the trap answer!
🔎 Find a first then ➡️ Forward
Q6.   T₆ = 44 and d = 5. Find T₁, then find T₁₃.
Step 1: Find a
T₆ = a + (6−1)×d = a + 5d← 5 jumps from T₁ to T₆
a + 5×5 = 44 → a + 25 = 44 → a = 19
Step 2: Find T₁₃
T₁₃ = 19 + (13−1)×5 = 19 + 60 = 79← coefficient = 13−1 = 12
Check: T₆ from a=19: 19+25 = 44 ✓

🏆 You are ready for the test when...

  • You always write Tₚ = a+(p−1)d (not a+pd) before adding
  • You add coefficients correctly for T₃+T₅, T₃+T₆, T₄+T₇
  • For compound questions: find a first, then use Tₙ = a+(n−1)d for the second part
  • Going backwards from T₅ you subtract 4d (not 5d) — the (n−1) rule works in reverse too
  • You always verify by substituting back into the original sum
  • On test morning: one last look at your 🗺️ Pocket Map — then solve from memory!
