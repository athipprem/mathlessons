## The calibration rule (Lui, 21 Sep 2026 — refines standing rule E.9 / cycle-7 §3.9)

> *"imo, yr basic & intermediate tiers should b the same level on the book while applied tier must not b under
> the book's level — it should b a bit harder than the book to challenge him."*

Translated into build instructions:
- **Basic tier = the book's own easiest material** (its Recall page, and the first activity or two of a unit) —
  not softer than the book, not harder. Single-step, heavily scaffolded.
- **Intermediate tier = the book's own core/mid activities** — the bulk of the unit's practice, where the new
  mechanic is drilled directly, sometimes across 2 unlike-format sub-parts, but still essentially one operation
  per item.
- **Applied tier must sit ABOVE the book's own hardest regular material** — not merely "not appear unchanged in
  the book" (the old, weaker phrasing of rule 3.9), but genuinely harder than the hardest thing the book itself
  contains, including the book's own final "Solving Word Problems" activities and its own "Let's Find Out"
  extension section.

## The concrete, checkable bar for "Applied must exceed the book"

Four structural moves recur across the book's own hardest items (A11–A13, "Let's Find Out"). **An Applied-tier
question should use at least one of these, and a unit's Applied set as a whole should use more than one across
its 4 questions:**

1. **Chain 2–3 operations of the unit's own mechanic**, not one — e.g. not "convert this improper fraction" but
   "find this, then use it to find that, then combine."
2. **Reverse-solve through 2+ layers**, not 1 — given an end state after two successive reductions, work
   backward through both, not just one (A13 Q1's three-layer rubber-band problem is the book's own ceiling
   example).
3. **Withhold a fraction the student must supply themselves** — the concert-audience problem (A13 Q4) never
   states what fraction of the children are boys; Prem has to notice the boy+girl count IS the "rest," find the
   total from the two given fractions, then compute a fresh fraction from raw counts. This is a materially
   different demand from "apply the fraction you were handed."
4. **Cross-link the unit's mechanic to a different strand** — Activity 8's fraction-sided composite perimeter,
   and "Let's Find Out"'s fraction-of-area geometric sequence, both borrow from Geometry/Patterns to raise the
   ceiling without inventing new fraction content. This is the cheapest lever when a 4th Applied question is
   needed and a 3-layer reverse-chain would be repetitive.

**A single reverse step (2/5 of a number is 18, find the whole) or a single division-plus-interpretation
question (29 cupcakes ÷ 6 boxes, how many full boxes and how many left over) is Intermediate-book-level by this
standard, not Applied** — it matches Activity 3/Recall-tier reverse items, not Activity 11–13.

## How to use this file when no book pages exist for the current chapter (Ratio, Volume, Statistics, …)

The specific fraction numbers above don't transfer. The STRUCTURE does:
1. Basic = the simplest, most scaffolded form of the unit's new mechanic, one step.
2. Intermediate = the same mechanic run at full mechanical difficulty (the book's own "Activity 2" energy —
   the least forgiving version of the core computation, still one operation).
3. Applied = apply 2+ of the four structural moves above, using THAT unit's own mechanic in place of fractions:
   chain 2–3 uses of it, reverse-solve 2+ layers, withhold a piece of information the student must derive, or
   cross-link it to a different strand already taught. **When building a new unit's Applied tier, explicitly
   check each Applied question against this checklist before shipping** — it replaces the older, weaker "would
   this look unchanged in the book?" test from rule 3.9, which only ruled out UNDER-difficulty and never set a
   real ceiling to climb toward.

  applies to a real source the same way it applies to a prior unit's own test.
