You already understand sequences! 🎉

In Unit 16, you got 5/5 on sequences — and you left a note:
"Don't understand the formula, so I just list it down."

Here's the thing — listing is correct! It's exactly the right thinking.
This lesson shows you that the formula is just a shortcut for listing — nothing magic, nothing scary.

⚠ Why the formula matters

Listing works for T₁₅ (15 terms). But what if ISA asks for T₅₀ or T₁₀₀? You'd need to list 100 terms — that takes too long. The formula gets you there in 3 seconds.

Let's start with a sequence you know

Here's the sequence: 3, 7, 11, 15, 19, 23, …

T₁=3 →+4 T₂=7 →+4 T₃=11 →+4 T₄=15 →+4 …
Key observation
Every term is +4 from the one before. The first term is 3. These two facts are all we need.

The secret: count the jumps

When you list to find T₅, you do this:

TermValueHow many +4 jumps from T₁?
T₁30 jumps → 3 + 0×4 = 3
T₂71 jump → 3 + 1×4 = 7
T₃112 jumps → 3 + 2×4 = 11
T₄153 jumps → 3 + 3×4 = 15
T₅194 jumps → 3 + 4×4 = 19
T₁₀?9 jumps → 3 + 9×4 = 39
T₅₀?49 jumps → 3 + 49×4 = 199
The pattern
To get term n, you make (n − 1) jumps of +4 from the start.
So: Term n = 3 + (n − 1) × 4
Why (n − 1) and not n?
T₁ needs 0 jumps (not 1). T₅ needs 4 jumps (not 5). It's always one less than the term number.

This IS the formula

Tn = a + (n − 1) × d
a = first term
n = term number you want
d = common difference (the jump)

You are not memorising a magic rule. You are just counting jumps: start at a, take (n−1) jumps of size d.

Using the formula — 3 worked examples

Type A — Find a specific term

Q: The sequence is 5, 9, 13, 17, … Find the 20th term.
1
Identify: a = 5, d = 4, n = 20
2
Substitute: T₂₀ = 5 + (20 − 1) × 4
3
= 5 + 19 × 4 = 5 + 76
T₂₀ = 81

Type B — Find the first term

Q: In an arithmetic sequence, d = 3. The 6th term is 20. Find the first term.
1
Known: d = 3, T₆ = 20, n = 6
2
Formula: 20 = a + (6 − 1) × 3 = a + 15
3
a = 20 − 15
First term a = 5

Type C — Find d from two terms

Q: The 3rd term is 11 and the 7th term is 23. Find d and T₁.
1
From T₃ to T₇ is 4 jumps. Gap = 23 − 11 = 12.
2
d = 12 ÷ 4 = 3
3
T₃ = a + 2d → 11 = a + 6 → a = 5
d = 3, first term = 5, so T₁₀ = 5 + 9×3 = 32

Tn = a + (n − 1) × d

a = first term
The starting value of the sequence
d = common difference
The fixed jump between terms (+ve or −ve)
n = term number
Which term you want to find
Why (n − 1)?
T₁ = 0 jumps, T₂ = 1 jump, T₅ = 4 jumps — always one less
3 types to know
Type A — Given a, d, n → find Tₙ (substitute directly)
Type B — Given d and one term → find first term a (rearrange)
