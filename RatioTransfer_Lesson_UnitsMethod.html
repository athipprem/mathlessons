🔄 UNITS SHIFT move — "a ratio that CHANGES after giving / removing / joining"

Trigger words: "in the ratio…", then "gives / removes / joins / adds", then a NEW situation (equal, or a new ratio).
Method: write the ratio as UNITS of n (5:3 → 5n and 3n) → apply the change → build the equation.

A Ratio Is a Recipe of Equal Boxes

"Anya and Boon have stickers in the ratio 5 : 3" means: Anya has 5 equal boxes, Boon has 3 of the SAME size boxes. We just don't know the box size yet — call it n.

Find n, and you know EVERYTHING. That's the whole method.

🔑 The Units Shift Chain

1️⃣ Write units: ratio 5:3 → 5n and 3n
2️⃣ Apply the change: gives 12 away → 5n−12. Receives 12 → 3n+12. Someone joins → +. Removed → −.
3️⃣ Build the equation from the NEW situation: "equal" → =. "New ratio 6:5" → compare as fractions.
4️⃣ Solve for n (you mastered this at U21!), then answer the ACTUAL question.
5️⃣ Check the new situation with real numbers.

⚠ The question usually asks about the START. After solving, go back to 5n and 3n — not the after-change numbers!

Worked Examples — Three Change Types

Type 1: GIVE until equal  Ratio 7:3. First gives 16 to second → equal. Starting numbers?

Units: 7n and 3n← step 1, always
Change: 7n−16 and 3n+16← one loses, other GAINS the same 16
Equal: 7n−16 = 3n+16
4n = 32 → n = 8
Start: 7×8 = 56 and 3×8 = 24
✓ Check: 56−16 = 40, 24+16 = 40. Equal ✓

Type 2: REMOVE until equal  Ratio 5:2. 12 removed from first → equal. How many in second?

Units: 5n and 2n. Change: 5n−12 (second unchanged!)← removed = gone, nobody receives it
5n−12 = 2n → 3n = 12 → n = 4
Second = 2×4 = 8
✓ Check: 20−12 = 8 = 8 ✓

Type 3: JOIN with a NEW ratio  Girls:boys = 4:3. 6 boys join → new ratio 8:7. How many girls?

Units: G = 4n, B = 3n. Change: B becomes 3n+6
New ratio: 4n / (3n+6) = 8 / 7← write the new ratio as a fraction pair
Cross-multiply: 7×4n = 8×(3n+6)
28n = 24n + 48 → 4n = 48 → n = 12
Girls = 4×12 = 48
✓ Check: boys 36+6 = 42. 48:42 = 8:7 ✓

Practice

Units → change → equation → solve n → answer the question asked → check.

Q1.   Mali and Nok share 88 baht in the ratio 6 : 5. How much does each get?
6+5 = 11 units. 88 ÷ 11 = 8 per unit
Mali = 48, Nok = 40. Check: 48+40 = 88 ✓
Q2.   Tan and Win have marbles in the ratio 9 : 5. Tan gives 14 marbles to Win and now they have equal numbers. How many marbles did Tan START with?
Units: 9n, 5n. Change: 9n−14 = 5n+14
4n = 28 → n = 7. Tan started with 9×7 = 63
✓ Check: 63−14 = 49, 35+14 = 49 ✓
Q3.   A jar has orange and green sweets in the ratio 7 : 4. After 15 orange sweets are eaten, there are equal numbers. How many GREEN sweets are in the jar?
Units: 7n, 4n. Eaten = removed: 7n−15 = 4n← green side unchanged
3n = 15 → n = 5. Green = 4×5 = 20
✓ Check: 35−15 = 20 = 20 ✓
Q4.   The ratio of girls to boys in art club is 5 : 4. After 6 more boys join, the ratio becomes 5 : 6. How many GIRLS are in the club?
Units: G = 5n, B = 4n. Change: B → 4n+6
New ratio: 5n / (4n+6) = 5 / 6
Cross: 30n = 20n + 30 → 10n = 30 → n = 3
Girls = 5×3 = 15. Check: boys 12+6 = 18. 15:18 = 5:6 ✓
📖 What You Learned Today
The trigger:A ratio + something moves (give/remove/join) + a new situation = UNITS SHIFT. Step 1 always:Ratio 5:3 → write 5n and 3n. The boxes are equal — that's the magic. Give vs remove:GIVE: one side −, other side +. REMOVE/EATEN: only one side changes. New ratio given:Write as fractions and cross-multiply. Answer the question:Usually the START amount → go back to 5n, 3n.

🏆 You are ready for the U26 test when...

  • You write the units (5n, 3n) before anything else
  • You know GIVE changes both sides but REMOVE changes one
  • You always check the new situation with real numbers
  • All three moves on the map make you say "I know which one this is!"
