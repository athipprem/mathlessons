🔢 The Secret Inside a Number

Why learn this?

Every number is made of digits — the number 47 is the digits 4 and 7. If you add the digits (4 + 7 = 11) you get a secret clue about the number. This "digit sum" is how you quickly check if something divides by 3 or 9, how puzzle-makers hide numbers, and how barcodes catch mistakes. Contests ask things like "how many numbers have a digit sum of 5?" — and once you know the trick, you just list them in order, no guessing.

digit sum = ADD all the digits of the number

For 47:  4 + 7 = 11. That's it — the digit sum of 47 is 11.

Finding a Digit Sum

Just split the number into its digits and add. Take it one digit at a time:

53 → 5 + 3 = 8
90 → 9 + 0 = 9 ← a 0 adds nothing, but don't forget it
264 → 2 + 6 + 4 = 12 ← three digits? add all three

⚠️ A digit sum is NOT the number times something. 90 is not "9". You ADD the digits: 9 + 0 = 9. For 264 you must add all three: 2 + 6 + 4.

🗺️ Counting Numbers by Digit Sum

Question: "How many 2-digit numbers have a digit sum of 5?" Don't guess — go in order with this map:

1Go through each tens digit in order: 1, 2, 3, …
2For each one, the ones digit must make the total 5. So ones = 5 − tens.
3If that ones digit is 0–9, it works — write the number. Then count them all.

Remember: a 2-digit number can't start with 0, so the tens digit begins at 1.

Worked Example

How many 2-digit numbers have a digit sum of 5? Go tens digit by tens digit:

TensOnes (= 5 − tens)Number
1414 ✓
2323 ✓
3232 ✓
4141 ✓
5050 ✓
6−1 ✗stop — ones can't be negative
Count them: 14, 23, 32, 41, 50 = 5 numbers

Once the ones digit would go below 0, you've found them all. Neat and complete — no guessing.

📖 Digit Problems — in one line

Digit sum = add all the digits. To count by digit sum, go tens-digit by tens-digit in order and list them.

Listing in order means you never miss one and never count twice.

🏆 You've got it when…

  • You find the digit sum of 264 by adding 2 + 6 + 4 = 12
  • You count "digit sum = 6" by going 1→5, 2→4, 3→3… in order

You now have BOTH number-detective tricks: remainders and digit sums. Ready for the test!
