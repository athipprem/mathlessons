😕 You know the value — but not the position

You already know how to go forward: given a, d, and n → find Tn.
But what happens when someone gives you Tn and asks: which term number is it?

A sequence has a = 3 and d = 5.
One of the terms equals 78.  Which term is it?
❌ The listing approach — why it fails
T₁ = 3
→
T₂ = 8
→
T₃ = 13
→
T₄ = 18
→
T₅ = 23
→
…

You'd need to list all the way to T₁₆ = 78. That's 16 terms — fine for small n, but what if the answer is T₁₀₀ or T₅₀₀?

✅ The formula approach — one line
Tn = a + (n − 1) × d   →   78 = 3 + (n − 1) × 5

Solve for n → answer in seconds, no listing needed.

🔑 The key idea
Know:
a, d, Tn
⇨
Find:
n

The formula Tₙ = a + (n−1) × d already contains n. When we know Tn, a, and d — we just solve the equation for n, exactly like equation solving.

🔢 The 3-Step Reverse Method

To find n when you know Tₙ, a and d — follow these three steps every time.

1 Write formula Write: Tₙ = a + (n−1) × d Always start here
2 Substitute Replace Tₙ, a, and d with their values n is still unknown
3 Solve for n Subtract a → divide by d → add 1 Answer: n = ?
🔍 Step 3 in Detail

Once you substitute, you get an equation like this:

78 = 3 + (n − 1) × 5

Now solve step by step — treat (n−1) as the thing you're finding first:

3a Subtract a 78 − 3 = 75   → (n−1) × 5 = 75 move a to left side
3b Divide by d 75 ÷ 5 = 15   → n−1 = 15 remove the ×d
3c Add 1 n = 15 + 1 = 16 n = 16 ✓
Always do 3c! n = (Tn − a) ÷ d then add 1. The +1 comes from the (n−1) in the formula. Missing it gives you the wrong term number.

📝 Worked Example 1
A sequence has first term a = 3 and common difference d = 5. The nth term is 78. Find n.
Step 1: Write formula  →  Tn = a + (n−1) × d
Step 2: Substitute  →  78 = 3 + (n−1) × 5
Step 3a: 78 − 3 = 75  →  (n−1) × 5 = 75
Step 3b: 75 ÷ 5 = 15  →  n−1 = 15
Step 3c: n = 15 + 1 = 16  ✓  Check: T₁₆ = 3 + 15×5 = 78 ✓
📝 Worked Example 2
A sequence has first term a = 10 and common difference d = 4. The nth term is 58. Find n.
Step 1: Tn = a + (n−1) × d
Step 2: 58 = 10 + (n−1) × 4
Step 3a: 58 − 10 = 48  →  (n−1) × 4 = 48
Step 3b: 48 ÷ 4 = 12  →  n−1 = 12
Step 3c: n = 12 + 1 = 13  ✓  Check: T₁₃ = 10 + 12×4 = 58 ✓
Always verify: plug n back into Tn = a + (n−1)×d.
If it equals the given Tn, you're correct.

🏆 Lesson Summary — Finding n
StepWhat to doExample (a=3, d=5, Tₙ=78)
1Write the formulaTₙ = a + (n−1) × d
2Substitute Tₙ, a, d78 = 3 + (n−1) × 5
3aSubtract a from both sides75 = (n−1) × 5
3bDivide both sides by d15 = n−1
3cAdd 1 to get nn = 16 ✓
The #1 mistake: forgetting to add 1 at the end.
After dividing by d, you have (n−1). You must add 1 to get n.
📌 Quick reference
n = (Tn − a) ÷ d  +  1

This only works when (Tₙ − a) divides exactly by d — always check!
